# JARVIS — голосовой помощник для Windows · 0.2

Русский локальный помощник: **услышать команду → открыть браузер по умолчанию → ответить голосом**.

Основа: C# / .NET 10 / WPF / NAudio. Отдельный Python-процесс: Vosk, Silero VAD, faster-whisper (`small`, CPU INT8), Piper (русские голоса Денис и Дмитрий). Интернет нужен при подготовке; во время работы речевой модуль использует только локальные модели. Облачного ИИ в этой версии нет.

## Запуск на подготовленном компьютере

1. Дважды нажать **`Start-Jarvis.cmd`** в папке проекта.
2. Дождаться сообщения «Готов к работе». Открыть **«Настройки» → «Микрофон»** и проверить устройство ввода. По умолчанию выбирается устройство связи Windows.
3. В **«Настройки» → «Голос»** выбрать тембр и характер звучания, нажать **«Прослушать»**, затем **«Сохранить»**. По умолчанию: Денис, роботизированный «Синтез», эффект 45%.
4. На главном экране нажать **«Начать»** и сказать **«Открой браузер»** или **«Джарвис, запусти браузер, пожалуйста»**.
5. Сделать небольшую паузу: фраза завершится автоматически. Распознанный текст и результат появятся в окне.

**«Стоп» или Esc** прекращают прослушивание и ответ. Отмена не закрывает уже открытый браузер. Микрофон изначально выключен. После обычной команды он также выключается.

Обычный запуск через `.cmd` открывает приложение напрямую и не требует разрешения PowerShell-скриптов. Если обязательные файлы отсутствуют, окно запуска остаётся открытым с объяснением. Политика PowerShell относится только к отдельным скриптам подготовки и сборки.

Для обращения по имени открыть **«Настройки» → «Поведение»**, включить **«Ожидать имя „Джарвис“»**, сохранить и нажать «Начать». Можно сказать имя, сделать паузу и продолжить командой. Ожидание — 8 секунд по умолчанию, настраивается от 4 до 15 секунд. Имя отделяется от команды; если продолжения нет, помощник молча возвращается к ожиданию имени. После ответа ожидание также возобновляется. Этот режим не является проверенной защитой от активации на речь из фильма. На время озвучки микрофон отключён; голосового перебивания пока нет.

Главный экран показывает состояние, звуковую волну, последние реплики и журнал. Волна реагирует на фактическую громкость входа и ответа. В меню **«Вид»** можно скрыть журнал; **Ctrl+,** открывает настройки. Настройки сохраняются между запусками, а микрофон при запуске всегда выключен. Голосовые режимы: естественный, роботизированный «Синтез» и «Радиоканал»; регулируются сила эффекта, темп и громкость.

## Поддержанные фразы

- «Открой браузер» / «Запусти браузер» / «Включи браузер».
- «Джарвис, открой браузер, пожалуйста».
- «Пожалуйста, открой мне браузер».
- «Отмена» / «Стоп» — отмена распознанной команды; для немедленной остановки служит кнопка или Esc.

Это ограниченная грамматика. Она не исполняет произвольные программы, команды оболочки или длинные составные поручения. Отрицания, вопросы и посторонние фразы не должны совпадать с правилом запуска. Ошибки распознавания всё ещё возможны: первая версия нужна именно для их измерения.

## Подготовка с нуля

Windows x64, подключённые микрофон и аудиовыход. Понадобится несколько гигабайт свободного места для SDK, окружения, моделей и кэшей.

Из PowerShell в корне проекта:

```powershell
.\scripts\setup.ps1
```

Скрипт готовит .NET SDK и Python внутри `.tools` / `.venv`, загружает зафиксированные модели, выполняет проверки и собирает приложение в `artifacts/prototype`. Он не меняет глобальную политику PowerShell. Если корпоративная политика запрещает запуск скриптов, нужно использовать разрешённый организацией способ сборки.

При уже подготовленном окружении:

```powershell
.\scripts\build.ps1 -Test
.\.venv\Scripts\python.exe scripts\test_speech.py
```

Перед пересборкой закрыть окно Джарвиса. Приложение запускается в обычном пользовательском сеансе: ограниченное окружение разработчика может мешать доступу к устройствам, настройкам браузера и проверке его окна. Права администратора приложению не нужны.

## Что проверяется

- C#-тесты: разбор команд, сохранение и нормализация настроек, повреждённый файл.
- Python-тесты: выделение реплики, ожидание после имени, команда без паузы, тайм-аут, отмена и обработка голоса.
- `scripts/test_speech.py`: реальные модели, синтетическая русская запись, распознавание файла и потока, тишина, имя с двухсекундной паузой, молчание после имени, три варианта голоса. Это технический тест, не замена записи голоса пользователя.
- Приложение принимает `--test-audio <PCM16-mono-16k.wav> --report <путь-в-work>` для сквозной проверки реального запуска браузера и воспроизведения. Этот режим **действительно открывает браузер**, если распознана поддержанная команда.

Проверки текущей версии: [отчёт 0.2](docs/V0.2-VALIDATION.md). Первый живой прогон: [отчёт о прототипе](docs/PROTOTYPE-VALIDATION.md).

## Структура

| Папка | Содержимое |
|---|---|
| `src/Jarvis.App` | WPF-окно, звук, запуск браузера, управление голосовым процессом |
| `src/Jarvis.Core` | Ограниченный разбор команд без зависимости от Windows |
| `speech/jarvis_speech` | Распознавание, VAD, активация, синтез; без выполнения системных команд |
| `tests` | Проверки C# и Python |
| `scripts` | Подготовка, сборка, запуск и речевой тест |
| `docs` | Каталог навыков, выбранный стек, протокол и результаты |
| `models.lock.json` | Источники, версии и SHA-256 моделей |

`.tools`, `.venv`, `models`, `artifacts`, `data` и `work` не входят в Git. Настройки находятся в `data/settings.json`. Аудио микрофона не сохраняется. Распознанные фразы видны только в ограниченной истории текущего окна. Скрипт технической проверки сохраняет **синтетические** аудиофайлы и отчёты в `work`.

## Границы версии 0.2

Нет Steam/Xbox, фильмов, облачного ИИ, трея, автозапуска, GPU-профиля и установщика. Проверка браузера подтверждает видимое окно соответствующего процесса, а не создание конкретной новой вкладки. Роботизация — собственный звуковой эффект поверх Piper, а не голос актёра из фильма. Стойкость к фоновым разговорам, эху, долгой работе и игровая нагрузка ещё не подтверждены.

Разделение экранов и правила расширения: [архитектура интерфейса](docs/UI-ARCHITECTURE.md).

Планы: [каталог навыков](docs/JARVIS-project-and-skills-catalog.md) и [выбор стека](docs/JARVIS-technology-stack.md). Фактические версии зависимостей находятся в `uv.lock`, `packages.lock.json` и `global.json`.

Сторонние компоненты и модели имеют собственные лицензии: [источники и лицензии](docs/THIRD-PARTY.md). В репозитории хранятся исходники прототипа; лицензия на распространение собственного приложения пока не выбрана.
