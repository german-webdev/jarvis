# JARVIS — персональный голосовой помощник · 0.15.0

## Поиск в браузере через ChatGPT

В меню **«Нейросети»** выбери активное подключение ChatGPT и включи **«Отправлять нейросети непонятные фразы»**. Скажи или введи **«Открой YouTube и найди видео про котиков»**. JARVIS откроет отдельный Edge, покажет найденные видео и предложит открыть страницу результатов. Кнопка «Стоп» и фраза «Останови задачу» во время голосового запроса прерывают поиск.

Для браузерных задач нужны установленный Edge и интернет. История между запросами не хранится. Рабочая ветка `codex/ai-tools` начинается со снимка 0.14.1 после [отката](docs/ROLLBACK-2026-11-09.md).

Предыдущие изменения сохранены: [длинные ответы 0.13.5](docs/LONG-REPLIES-0.13.5.md), [Mini 0.13.4](docs/MINI-JARVIS-0.13.4.md), [интерфейс 0.13.2](docs/UI-POLISH-0.13.2.md).

Русский локальный помощник: **услышать команду → выполнить локальный навык → показать результат и ответить голосом**. Браузер, приложения и игры, папки программ, управление окнами и воспроизведением, скриншоты, громкость, время и дата.

Основа: C# / .NET 10 / WPF / NAudio. Отдельный Python-процесс: Vosk, Silero VAD, faster-whisper (`small`, CPU INT8), Piper (русские голоса Денис и Дмитрий). Речевой модуль использует локальные модели. Внешние нейросети подключаются отдельно и по умолчанию выключены.

## Установка и запуск

Текущий установщик — `artifacts/release/JARVIS-Setup-0.15.0-win-x64.exe`. Перед обновлением закрой JARVIS, включая трей. Для Windows 10/11 x64. Установщик включает .NET, Python, речевые модели и браузерный инструмент. [Проверки выпуска](docs/RELEASE-0.15.0.md).

Крестик окна предлагает **«Убрать в трей»** или **«Закрыть приложение»**. Крестик диалога отменяет действие. Повторный запуск возвращает существующее окно. Автозапуск Windows и автоматическое начало прослушивания включаются отдельно в **«Настройки → Приложение»**, по умолчанию оба выключены. Подробности и проверки: [работа на рабочем столе 0.8](docs/DESKTOP-0.8.md).

Язык интерфейса — **Русский / English**, выбирается в **«Настройки → Приложение → Язык интерфейса»** и применяется после сохранения без перезапуска. Голосовые команды и распознавание пока работают на русском.

**JARVIS → Нейросети**: добавление профилей API, совместимого с OpenAI, Ollama, прямого браузерного входа ChatGPT и подписки через Claude Code. Аккаунты не подключаются автоматически. После самостоятельной настройки можно сказать **«Спроси нейросеть…»**. Обычные команды остаются локальными. Возможности, ограничения и состояние проверок: [подключения 0.9](docs/AI-CONNECTIONS-0.9.md).

1. Установить JARVIS и открыть его из меню «Пуск». Для прототипа — дважды нажать **`Start-Jarvis.cmd`** в папке проекта.
2. Дождаться сообщения «Готов к работе». Открыть **«Настройки» → «Микрофон»** и проверить устройство ввода. По умолчанию выбирается устройство связи Windows.
3. В **«Настройки» → «Голос»** выбрать тембр и характер звучания, нажать **«Прослушать»**, затем **«Сохранить»**. По умолчанию: Денис, роботизированный «Синтез», эффект 45%.
4. На главном экране нажать **«Начать»** и сказать **«Открой браузер»** или **«JARVIS, запусти браузер, пожалуйста»**.
5. Сделать небольшую паузу: фраза завершится автоматически. Распознанный текст и результат появятся в окне.

**Кнопка «Стоп» или Esc** прекращают прослушивание и ответ, сбрасывают незавершённый выбор игры. Временный Edge браузерной задачи закрывается при завершении или остановке. Микрофон изначально выключен. В режиме по кнопке после обычной команды он также выключается. Если требуется уточнение, помощник после вопроса снова слушает ответ.

Обычный запуск через `.cmd` открывает приложение напрямую и не требует разрешения PowerShell-скриптов. Если обязательные файлы отсутствуют, окно запуска остаётся открытым с объяснением. Политика PowerShell относится только к отдельным скриптам подготовки и сборки.

Ожидание имени включено по умолчанию для нового профиля. Для изменения режима открыть **«Настройки» → «Поведение»**. Чтобы начать слушать, нажать «Начать». Можно сказать имя, сделать паузу и продолжить командой. Ожидание — 8 секунд по умолчанию, настраивается от 4 до 15 секунд. Имя отделяется от команды; если продолжения нет, помощник молча возвращается к ожиданию имени. После ответа JARVIS ещё 5 секунд ждёт следующую команду без имени; при тишине возвращается к ожиданию имени. Начатой фразе даёт закончиться. На распознанное имя подаётся короткий звуковой сигнал. Обе опции отключаются в настройках поведения. Этот режим не является проверенной защитой от активации на речь из фильма. На время озвучки микрофон отключён; голосового перебивания пока нет.

Главный экран показывает состояние, звуковую волну, последние реплики и журнал. Волна реагирует на фактическую громкость входа и ответа. В меню **«Вид»** можно скрыть журнал; **Ctrl+,** открывает настройки. Настройки сохраняются между запусками; микрофон при запуске включается только по отдельной сохранённой опции. Голосовые режимы: естественный, роботизированный «Синтез» и «Радиоканал»; регулируются сила эффекта, темп и громкость.

Текущее состояние и оставшиеся этапы: [план реализации](docs/IMPLEMENTATION-STATUS.md). Открытие сайтов и их каталог: [навыки 0.7](docs/SKILLS-0.7.md).

## Поддержанные фразы

- «Открой браузер» / «Запусти браузер» / «Включи браузер».
- «Открой YouTube», «Открой Кинопоиск», «Открой почту» (Gmail), «Открой почту Яндекса», «Открой Ozon», «Открой Яндекс еду», «Открой ПлатиМаркет». Каталог: «JARVIS → Сайты».
- «JARVIS, открой браузер, пожалуйста».
- «Пожалуйста, открой мне браузер».
- «Отмена» — отмена команды; «Стоп» / «Останови» — пауза плеера, а во время уточняющего вопроса — отмена выбора. Кнопка «Стоп» и Esc выключают прослушивание.
- «Запусти телеграм», «Открой стим», «Запусти икс бокс» — после обнаружения приложений.
- «Запусти Call of Duty» — по официальному названию найденной игры, без обязательных дополнительных названий.
- «Сделай скриншот», «Открой скриншоты».
- «Сделай громче» / «Сделай погромче», «Сделай тише» / «Сделай потише» — громкость плеера ±10 пунктов. «Систему громче», «Систему тише», «Громкость 30 процентов» — общая громкость Windows; «Выключи звук», «Включи звук».
- «Сколько времени», «Какое сегодня число», «Покажи команды».
- «Закрой телеграм», «Выключи стим», «Закрой игру» (для найденной запущенной игры Steam).
- «Закрой окно», «Сверни окно», «Переключись на браузер», «Переключись на телеграм».
- «Включи музыку», «Выключи музыку» / «Останови» / «Стоп» / «Пауза», «Продолжи», «Следующий трек» / «Дальше», «Предыдущий трек» / «Назад».
- «Открой папку с Сабнавтикой», «Открой каталог Форзы», «Открой папку Телеграма».

Закрытие — обычный запрос окну, с возможностью сохранить документы; программа может остаться в трее. Активное окно — внешнее окно на переднем плане, сам JARVIS исключён. При нескольких совпадениях помощник уточняет выбор. Музыкальное приложение выбирается в «JARVIS → Мультимедиа» или голосом после «Включи музыку». Короткие медиакоманды выбирают текущий источник Windows; единственный играющий источник имеет приоритет перед источниками на паузе. Явные команды про музыку обращаются к музыкальному плееру. Поддержка команд зависит от приложения или сайта. Папка определяется по установке Steam, исполняемому файлу, ярлыку или регистрации Windows / Xbox. Защита системных папок не меняется. Подробности: [новые навыки 0.5](docs/SKILLS-0.5.md).

**Меню «JARVIS» → «Приложения и игры» → «Найти установленные»** автоматически собирает каталог Windows / Xbox и всех библиотек Steam. Официальное название работает сразу после сохранения. Варианты вроде «сабнавтику», «форзу», «форза шесть», «контру», «колду» добавляются локально по правилам и встроенному словарю. Они видны в отдельной колонке; полный список — при наведении. Существующий каталог получает варианты без повторного поиска. Склоняется и последнее слово составного названия: «Яндекс Музыку». Word понимает «ворд», ward и wardo, Excel — «эксель» и «экссель». Word и WARDOGS запускаются по своим названиям без лишнего вопроса; уточнение требуется только при нескольких совпадениях в каталоге. Свои названия разделяются запятыми или точками с запятой, необязательны и сохраняются отдельно; ручное добавление `.exe` / `.lnk` также доступно. Подробности автопоиска: [навыки 0.3](docs/SKILLS-0.3.md), сопоставление имён: [названия и уточнения 0.4](docs/NAMES-AND-CHOICES.md).

Если установлена одна Forza, «Запусти форзу» запускает её. Если подходят несколько игр, JARVIS перечисляет варианты голосом. После окончания вопроса скажи **«шестую»**, **«Forza Horizon 6»** или **«вариант два»**, без повторного имени «JARVIS». На начало ответа — 10 секунд; «отмена» прекращает выбор. «Шестую» означает номер части, а «вариант два» — позицию в озвученном списке. В режиме текстовых команд ответ вводится через то же меню.

Меню **«JARVIS» → «Команда текстом»** выполняет те же действия без микрофона. Скриншоты сохраняются в `data/screenshots`; после снимка появляется кнопка открытия. Системная громкость и громкость голоса в настройках — разные параметры.

Это ограниченная грамматика. Она не исполняет произвольные программы, команды оболочки или длинные составные поручения. Отрицания, вопросы и посторонние фразы не должны совпадать с правилом запуска. Ошибки распознавания всё ещё возможны: первая версия нужна именно для их измерения.


## Мультимедиа и обновление · 0.11

**JARVIS → Мультимедиа** объединяет плееры, папки, музыку и видео. «Пауза» и «продолжи» относятся к текущему воспроизведению Windows, включая браузер; «останови музыку» — к выбранному музыкальному плееру. В список плееров автоматически попадают только распознанные мультимедийные приложения. Можно добавить свой плеер, папки или отдельные файлы.

Команды: «Включи фильм [название]», «Включи песню [название]», «Запусти плеер [название]». «Дальше»/«назад» переключают треки; «перемотай вперёд»/«перемотай назад» запрашивают сдвиг на 10 секунд. Поддержка зависит от источника. [Возможности и ограничения](docs/MULTIMEDIA-0.11.md).

Установщик распознаёт установленный JARVIS: предлагает обновление более старой версии или восстановление той же версии, сохраняя папку, настройки, каталоги и подключения. Перед обновлением нужно полностью выйти из JARVIS. Сборка и проверки выполняются локально; GitHub CI по просьбе пользователя не запускается.

В планы добавлены [навыки дизайна настольных интерфейсов и звуковое сопровождение](docs/DESKTOP-DESIGN-AND-SOUND-PLAN.md).

## Подготовка с нуля

Windows x64, подключённые микрофон и аудиовыход. Понадобится несколько гигабайт свободного места для SDK, окружения, моделей и кэшей.

Из PowerShell в корне проекта:

```powershell
.\scripts\setup.ps1
```

Скрипт готовит .NET SDK и Python внутри `.tools` / `.venv`, загружает зафиксированные модели, выполняет проверки и собирает приложение в `artifacts/prototype`. Он не меняет глобальную политику PowerShell. Если корпоративная политика запрещает запуск скриптов, нужно использовать разрешённый организацией способ сборки.

При уже подготовленном окружении:

```powershell
.\scripts\build.ps1 -Test
.\.venv\Scripts\python.exe scripts\test_speech.py
```

Перед пересборкой закрыть окно JARVIS. Приложение запускается в обычном пользовательском сеансе: ограниченное окружение разработчика может мешать доступу к устройствам, настройкам браузера и проверке его окна. Права администратора приложению не нужны.

## Что проверяется

- C#-тесты: разбор команд, сохранение и нормализация настроек, повреждённый файл.
- Python-тесты: выделение реплики, ожидание после имени, команда без паузы, тайм-аут, отмена и обработка голоса.
- `scripts/test_speech.py`: реальные модели, синтетическая русская запись, распознавание файла и потока, тишина, имя с двухсекундной паузой, повторная активация, молчание после имени, три варианта голоса, «сабнавтику» и короткий ответ «шестую». Это технический тест, не замена записи голоса пользователя.
- Приложение принимает `--test-audio <PCM16-mono-16k.wav> --report <путь-в-work>` для сквозной проверки реального запуска браузера и воспроизведения. Этот режим **действительно открывает браузер**, если распознана поддержанная команда.

## Структура

| Папка | Содержимое |
|---|---|
| `src/Jarvis.App` | WPF-окно, звук, запуск браузера, управление голосовым процессом |
| `src/Jarvis.Core` | Ограниченный разбор команд без зависимости от Windows |
| `speech/jarvis_speech` | Распознавание, VAD, активация, синтез; без выполнения системных команд |
| `tests` | Проверки C# и Python |
| `scripts` | Подготовка, сборка, запуск и речевой тест |
| `docs` | Каталог навыков, выбранный стек, протокол и результаты |
| `models.lock.json` | Источники, версии и SHA-256 моделей |

`.tools`, `.venv`, `models`, `artifacts`, `data` и `work` не входят в Git. Настройки находятся в `data/settings.json`. Аудио микрофона не сохраняется. Распознанные фразы видны только в ограниченной истории текущего окна. Скрипт технической проверки сохраняет **синтетические** аудиофайлы и отчёты в `work`.

## Границы версии 0.11.0

Нет поиска фильмов внутри сайтов и GPU-профиля. Локальные аудио/видео из добавленных папок открываются в приложении Windows по умолчанию. Офлайн-установщик поддерживает обновление и восстановление установленной версии. Подключения нейросетей опциональны; реальные подписки и модели проверяются после настройки пользователем. Запуск Steam / Xbox передаёт запрос клиенту, но не проверяет загрузку игрового меню. Обнаруживаются установленные записи Steam и зарегистрированные приложения Windows; нестандартные установки могут потребовать ручного добавления. Проверка браузера подтверждает видимое окно соответствующего процесса, а не создание конкретной новой вкладки. Подбор голоса отложен по решению пользователя. Стойкость к фоновым разговорам, эху, долгой работе и игровая нагрузка ещё не подтверждены.

Разделение экранов и правила расширения: [архитектура интерфейса](docs/UI-ARCHITECTURE.md).

Планы: [каталог навыков](docs/JARVIS-project-and-skills-catalog.md) и [выбор стека](docs/JARVIS-technology-stack.md). Фактические версии зависимостей находятся в `uv.lock`, `packages.lock.json` и `global.json`.

Сторонние компоненты и модели имеют собственные лицензии: [источники и лицензии](docs/THIRD-PARTY.md). В репозитории хранятся исходники прототипа; лицензия на распространение собственного приложения пока не выбрана.
