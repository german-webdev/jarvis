# Необязательные подключения нейросетей · 0.9.1

JARVIS предоставляет способы подключения, но не подключает аккаунты сам. У новой установки нет профилей, активного сервиса, сохранённых ключей и входов. Общий переключатель и отправка непонятных фраз выключены. Открытие окна настроек не обращается к сервисам.

## Где настроить

Меню **JARVIS → Нейросети** либо **Настройки → Приложение → Подключения нейросетей**. Интерфейс доступен на русском и английском.

1. Нажать «Добавить», назвать подключение и выбрать способ.
2. Для API/Ollama заполнить параметры и сохранить. Для ChatGPT нажать «Продолжить с ChatGPT»: профиль сохраняется автоматически, открывается браузер. Включение нейросети остаётся отдельным действием.
3. Подтвердить доступ в браузере и вернуться в JARVIS. При успешном входе показан аккаунт; нажать «Загрузить модели» и выбрать модель. Для Claude используется собственный вход установленного Claude Code, найденного автоматически.
4. Самостоятельно выбрать активное подключение, включить «Использовать нейросеть для ответов» и сохранить.

Можно хранить несколько подключений и переключаться между ними. Кнопка «Закрыть» не сохраняет несохранённые изменения. Удаление профиля применяется после сохранения; для завершения его подписочного входа сначала нужно нажать «Выйти из аккаунта».

## Поддерживаемые способы

| Способ | Что указывать | Как работает |
|---|---|---|
| API, совместимый с OpenAI | Базовый URL, обычно с `/v1`, имя модели, ключ при необходимости | `/models` для списка, `/chat/completions` для ответа. Это конкретный совместимый протокол, не поддержка всех существующих API |
| Ollama | Адрес сервера, обычно `http://localhost:11434`, имя модели | Нативные `/api/tags` и `/api/chat`. Локальная Ollama обычно не требует ключа; модели устанавливает пользователь |
| ChatGPT по подписке | Подтвердить доступ в браузере, затем выбрать модель | Прямой Sign in with ChatGPT: dynamic registration, PKCE, loopback callback. Ответы через разрешённый подпиской Responses API. Codex/ChatGPT EXE не требуется |
| Claude по подписке | Компонент Claude Code, автоматически найденный в PATH или `.local/bin`; модель необязательна | Вход самого Claude Code через `claude auth login`, ответы через `claude -p`. Отдельный профиль авторизации JARVIS; выбора EXE в интерфейсе нет |

Проверка HTTP-подключения получает список моделей, но не запускает генерацию. Проверка подписки проверяет вид входа, но не доказывает доступ к конкретной модели или наличие остатка лимита. Это устанавливается только успешным ответом на вопрос.

Доступность моделей и условия подписок могут меняться. Это адаптеры конкретных сервисов, а не универсальный OAuth для любой нейросети. Для другого сервиса нужен его поддерживаемый способ входа и отдельный адаптер. Для коммерческого распространения отдельно проверяется допустимый способ встраивания и регистрация приложения. Claude не предоставляет здесь прямой OAuth JARVIS: используется неизменённый официальный компонент и его собственная авторизация, без извлечения его токенов. Если он не установлен, интерфейс сообщает об этом; автоматическая установка ещё не реализована.

При входе видны этапы операции, отмена и кнопка повторного открытия страницы браузера. В ChatGPT локальный listener запускается до открытия браузера и слушает только `127.0.0.1` на свободном порту. Проверяются `state`, PKCE, подпись ID token, issuer, audience, срок, nonce, совпадение сохранённой личности и разрешение на использование подписки. Подтверждение браузера само по себе не считается успешным входом. Полный адрес авторизации и коды не выводятся в журнал. Вход не включает обработку неизвестных команд и не запускает генерацию.

## Как задать вопрос

**«Спроси нейросеть, почему небо голубое»** или **«Вопрос к нейросети: объясни OAuth»**. Для голосового вопроса ответ озвучивается; текстовый вопрос показывает ответ в карточке.

Непонятные фразы отправляются только при отдельном включении соответствующей настройки. Известные команды, поиск приложения в каталоге и уточнения выбора остаются локальными. При выключенной нейросети JARVIS сообщает, где её настроить; браузерный вход не запускается автоматически.

На этом этапе нейросеть отвечает на вопросы. Ответ модели не исполняется как команда. HTTP-запрос не содержит инструментов, файлов, каталогов, снимков экрана или истории пользователя. ChatGPT вызывается напрямую с `store:false`, `stream:true`; успех принимается только при `response.completed`. Claude запускается в отдельном пустом рабочем каталоге без инструментов/MCP/плагинов. Обычные действия на ПК по-прежнему выполняет диспетчер навыков JARVIS.

Ожидание ограничено; «Стоп» отменяет запрос и прерывает принадлежащий этому запросу дочерний процесс. Автоматического повторного платного запроса и переключения на другой сервис нет.

## Данные подключения

- Профили — `data/ai-connections.json`, вне Git. API-ключи защищены Windows DPAPI для текущего пользователя; в журнал и сообщения об ошибках ключ не выводится.
- При смене провайдера или адреса сохранённый ключ удаляется из черновика. Его необходимо ввести заново; иначе старый ключ не уйдёт на новый адрес.
- ChatGPT: `data/chatgpt-accounts/<id>.protected` — отдельная сессия каждого профиля, целиком зашифрованная Windows DPAPI. `host-id` — стабильный несекретный ID установки. Токены обновляются последовательно. При выходе выполняется отзыв сессии; если сервер недоступен, локальный выход сохраняется с явным предупреждением. Связь аккаунта и выданного client ID остаётся для повторного входа.
- Claude: `data/ai-sessions/<id>/`, вне Git. Сессией управляет официальный клиент. Старые сессии Codex из 0.9 не используются новым ChatGPT-подключением и автоматически не удаляются. Эти файлы не следует публиковать или отправлять вместе с диагностикой.
- JARVIS не копирует авторизацию уже открытых Codex/Claude и убирает переменные API-ключей из окружения своих подписочных процессов.
- Удалённые API требуют HTTPS. HTTP допускается только для loopback-сервера. Переадресация запросов отключена.

## Проверка этой версии

В дополнение к проверкам 0.9: полный loopback-цикл с тестовым браузерным запросом и имитатором OpenAI, подписанный тестовый ID token, зашифрованное сохранение, выход и повторный вход с тем же client ID/host ID. Отдельно проверены неверные state/nonce/подпись/issuer/audience/срок, подмена регистрации, отмена ожидания, ротация refresh token, формат подписочного Responses API и отклонение оборванного или ошибочного потока. Настройки остаются выключенными по умолчанию; выбора EXE в окне нет.

Реальные аккаунты и оплаченные запросы в автоматических тестах не используются. Публичные параметры OpenID OpenAI проверены по сети. Пользователь подтвердил завершение прямого входа ChatGPT и отображение аккаунта в JARVIS. Генерация и озвучивание ответа по подписке ещё не подтверждены пользователем. Для Claude проверена справка установленного клиента `2.1.71`; наличие клиента не доказывает успешную авторизацию.
