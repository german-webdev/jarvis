# Работа на рабочем столе · 0.8

Собственный значок встроен в `Jarvis.exe`, главное окно и трей. Исходный PNG, Windows ICO и запрос генератору находятся в `src/Jarvis.App/Assets`. Ярлык «JARVIS» запускает `artifacts/prototype/Jarvis.exe` напрямую, с рабочей папкой проекта. Для создания ярлыка после сборки есть `scripts/create-shortcut.ps1`.

## Закрытие и трей

Крестик главного окна открывает диалог с двумя кнопками:

- **Убрать в трей**: окно скрывается, текущий режим прослушивания и голосовой модуль продолжают работу.
- **Закрыть приложение**: микрофон, воспроизведение ответа, голосовой процесс и значок трея закрываются.

Крестик диалога и Esc отменяют действие; отдельной кнопки «Отмена» нет. Выбор не запоминается: крестик главного окна спрашивает каждый раз. «JARVIS → Выход» и «Закрыть приложение» в меню трея завершают приложение сразу.

Двойной щелчок по значку или повторный запуск `Start-Jarvis.cmd` возвращает существующее окно. В меню трея доступны открытие окна, начало и остановка прослушивания, настройки и выход. Подсказка значка показывает состояние микрофона. Windows может поместить значок в область скрытых значков.

При завершении сеанса Windows диалог выбора не показывается; голосовой процесс освобождается. Реальный выход из Windows не выполняется автоматическими проверками.

## Автозапуск

«Настройки → Приложение»:

- **Запускать при входе в Windows**: по умолчанию выключено; настройка создаёт только запись текущего пользователя `HKCU\Software\Microsoft\Windows\CurrentVersion\Run\JarvisVoiceAssistant`. Снятие флажка удаляет эту запись. Права администратора не нужны.
- **При автозапуске убирать окно в трей**: по умолчанию включено; обычный ручной запуск открывает окно.
- **Начинать прослушивание при запуске JARVIS**: по умолчанию выключено. При включении микрофон запускается один раз после готовности моделей, в выбранном режиме обращения. Перезапуск голосового модуля не включает его повторно автоматически.

Автозапуск использует опубликованный `Jarvis.exe --autostart`. Приложение умеет найти локальный .NET в `../../.tools/dotnet` без командного окна и глобальной установки. После перемещения проекта следует отключить и снова включить автозапуск, чтобы обновить путь. Ограничения автозагрузки в настройках Windows могут дополнительно запрещать запуск.

Старые настройки сохраняют выключенный микрофон при запуске. Каталоги приложений и сайтов не меняются.

## Язык интерфейса

«Настройки → Приложение → Язык интерфейса»: **Русский / English**. После «Сохранить» главное окно, меню и трей переводятся сразу; новые диалоги открываются на выбранном языке. Выбор сохраняется между запусками, для старых настроек используется русский.

Переведены настройки, каталоги, диалог закрытия, сообщения состояния и подписи журнала. Имена приложений, собственные названия и распознанные команды остаются без изменения. В английском интерфейсе примеры голосовых команд остаются русскими: язык распознавания и синтеза на этом этапе не переключается. Сообщения сторонних программ и Windows могут приходить на языке самой системы.

Тексты собраны в `src/Jarvis.App/Localization/strings.json`; ключ — исходный русский текст, значение — английский перевод. XAML ссылается на стабильные ресурсы, а `Ui` обновляет их при смене языка. Произвольные имена и текст пользователя не переводятся.

## Проверки

- 201 тест ядра, включая сохранение новых параметров и безопасную загрузку старых настроек.
- Отдельный тест настоящих WPF-окон: ровно две кнопки, отмена крестиком, скрытие без закрытия, восстановление того же окна, окончательный выход, запуск в трее, прямой выход через меню и завершение сеанса без диалога. Тест использует пустой каталог без моделей и не записывает микрофон. Захват экрана не используется.
- В том же тесте: смена языка без перезапуска, перевод главного окна, настроек, заголовков таблицы сайтов и кнопок закрытия, сохранение языка, перевод сообщений с параметрами без изменения текста команды.
- 31 тест Python и проверка стиля Python.
- Прямой запуск опубликованного приложения с удалёнными переменными `DOTNET_ROOT` и `DOTNET_ROOT_X64`: диагностический поиск приложений завершился с кодом 0.
- Проверка установленной сборки: запуск `--autostart` оставил живой процесс без видимого главного окна; второй запуск завершился с кодом 0 и вернул окно первого процесса. Созданный ярлык повторно прочитан: указывает на опубликованный EXE.

Реальный вход в Windows, работа микрофона в трее и внешний вид на разных масштабах экрана требуют пользовательской проверки. Ограничения распознавания речи из предыдущей версии остаются; этот этап не меняет модели и голос.
