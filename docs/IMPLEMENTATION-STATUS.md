# Состояние проекта · 8 ноября 2026 года

Исходный каталог — план возможностей, а не перечень уже реализованных функций. Текущий этап: помощник 0.10.0 с локальными навыками и необязательными настраиваемыми подключениями нейросетей.

| Область | Текущее состояние |
|---|---|
| Голосовая цепочка | Локальные модели, кнопка и ожидание имени, пауза после имени, голосовой ответ; пропуски и ошибки речи ещё встречаются |
| Интерфейс | Главный экран, журнал сеанса, визуализация звука, отдельные настройки и каталоги, русский и английский интерфейс |
| Приложения и игры | Автопоиск Steam и Windows/Xbox, ручное добавление, псевдонимы, ограниченные склонения и уточнение совпадений |
| Окна и папки | Открытие папки программы, обычное закрытие окна, сворачивание и переключение |
| Медиа и громкость | Выбор музыкального приложения, Play/Pause/Next/Previous, отдельная громкость плеера и общая громкость |
| Сайты | Каталог, адреса, дополнительные названия, открытие в браузере по умолчанию |
| Работа в фоне | Трей, диалог закрытия, восстановление окна повторным запуском, автозапуск и отдельное включение микрофона при старте |
| Нейросети | Профили совместимых API, Ollama, прямого OAuth ChatGPT и подписки через Claude Code; по умолчанию выключены. Пользователь подтвердил прямой вход ChatGPT; реальный ответ модели ещё не подтверждён |
| Питание компьютера | Выключение, перезагрузка, сон и гибернация с локальным одноразовым подтверждением и отменой; реальные переходы Windows ещё не проверены пользователем |
| Другие базовые навыки | Скриншот в файл, открытие папки скриншотов, время и дата |

В 0.9.2: справка с категориями и поиском, звуковой сигнал на имя, 5 секунд продолжения разговора. Полный обзор и границы проверок: [PROJECT-OVERVIEW.md](PROJECT-OVERVIEW.md).

## Следующие этапы

1. Повседневная работа: пользовательская проверка трея и входа в Windows, сон помощника, понятный сигнал готовности к команде, проверка длительной работы на фоне игры и фильма.
2. Пользовательская проверка системных действий в удобный момент. Расширение скриншотов: буфер и последний снимок.
3. Персонализация: редактор произвольных фраз, последовательности действий, профили, таймеры и заметки.
4. ИИ по необходимости: пользовательская проверка реальных подключений и подписок, дополнительные провайдеры, контекст диалога, OCR и разбор содержимого экрана. [Подключения 0.9](AI-CONNECTIONS-0.9.md).
5. Действия внутри сайтов: поиск ролика или фильма, выбор результата, воспроизведение на Кинопоиске; отдельно проверять каждый сценарий.
6. Подбор тембра и роботизация голоса — отложены по решению пользователя. Собственный значок, ярлык и [офлайн-установщик](INSTALLER-PLAN.md) готовы; автоматические обновления, подпись и профиль GPU остаются будущей работой.

Запуск игры через клиент не подтверждает появление игрового меню. Обнаружение записей Xbox не означает проверку каждой игры. Полная устойчивость к фоновым разговорам и собственному эху пока не подтверждена.

Детали текущих навыков: [0.6](SKILLS-0.6.md), [сайты 0.7](SKILLS-0.7.md). Исходные планы: [каталог навыков](JARVIS-project-and-skills-catalog.md), [стек](JARVIS-technology-stack.md).


## Дополнение 0.10.0 — установочная версия

Подготовлен автономный установщик `F:\AI\JARVIS\artifacts\release\JARVIS-Setup-0.10.0-win-x64.exe` для Windows 10 build 19041+ / Windows 11 x64. Личные данные, аккаунты и каталоги разработчика исключены. Установленный профиль хранится в `%LOCALAPPDATA%\JARVIS`; рабочий прототип продолжает использовать свою папку `data`. Подробности сборки, установки, проверок и оставшихся ограничений — [INSTALLER-PLAN.md](INSTALLER-PLAN.md). Подсказка подтверждения теперь требует одно слово «Подтверждаю»; старое «да подтверждаю» также принимается для совместимости.
