## Исторический выпуск · 0.14.0 · 9 ноября 2026

Локальный выпуск пяти функциональных этапов и голосового прерывания готов: контекст разговора в памяти процесса, разрешённые локальные задачи ChatGPT, пользовательские сценарии, поиск/открытие видео в отдельном браузере, чтение выбранного окна Windows и выбор вкладки. Полные результаты, контрольная сумма и ручная проверка: [RELEASE-0.14.0.md](RELEASE-0.14.0.md). Контракты этапов: [FUNCTIONAL-DEVELOPMENT-PLAN.md](FUNCTIONAL-DEVELOPMENT-PLAN.md).

Установщик: `artifacts/release/JARVIS-Setup-0.14.0-win-x64.exe`; пакет: `artifacts/package-0.14.0/payload`. Профиль пользователя автоматически не обновлялся. Финальные проверки: **479 Core / 52 App / 99 Python**, ruff; автономная загрузка моделей/синтез; синтетическая PCM-фраза дала `task_stop`; пакетный UIA helper проверен только на собственном окне. `artifacts/release` очищен штатным скриптом перед сборкой и содержит только текущий EXE, SHA-256 и README.

Следующий шаг — самостоятельное обновление пользователем и ручной smoke из release notes. Реальные tool calls ChatGPT, публичный YouTube, сторонние UIA-окна и микрофон/задержка остановки ещё не подтверждены. История ИИ хранится только до перезапуска; сценарии ограничены 1–3 launch/focus EXE; Windows-маршрут не использует vision. Не запускать commit/push/CI или автоматическую установку. Не включать устройства и не выполнять действия в личных приложениях ради автотеста.

Звуки, таймеры, заметки, подбор тембра, постоянная память, дополнительные провайдеры действий и GitHub Releases/Actions/автообновление остаются отдельным отложенным бэклогом. Перед каждой новой сборкой установщика обязателен `scripts/clear-release.ps1`, очищающий только `artifacts/release`.

## Следующие этапы

1. Повседневная работа: пользовательская проверка трея и входа в Windows, сон помощника, понятный сигнал готовности к команде, проверка длительной работы на фоне игры и фильма.
2. Пользовательская проверка системных действий в удобный момент. Расширение скриншотов: буфер и последний снимок.
3. Персонализация: редактор произвольных фраз, последовательности действий, профили, таймеры и заметки.
4. ИИ по необходимости: пользовательская проверка реальных подключений и подписок, дополнительные провайдеры, контекст диалога, OCR и разбор содержимого экрана. [Подключения 0.9](AI-CONNECTIONS-0.9.md).
5. Действия внутри сайтов: поиск ролика или фильма, выбор результата, воспроизведение на Кинопоиске; отдельно проверять каждый сценарий.
6. Подбор тембра и роботизация голоса — отложены по решению пользователя. Собственный значок, ярлык и [офлайн-установщик](INSTALLER-PLAN.md) готовы; автоматические обновления, подпись и профиль GPU остаются будущей работой.
7. После восстановления доступности GitHub CI — релизная сборка и проверки через GitHub Actions, публикация установщика в GitHub Releases. Добавить в JARVIS проверку новых опубликованных версий, загрузку обновления из GitHub и обновление установленного приложения с сохранением профиля. Это согласованный план, пока не реализован; до снятия ограничения сборки остаются локальными. Подробности — [план релизов и обновлений](INSTALLER-PLAN.md#план-релизов-и-обновлений-через-github).

Запуск игры через клиент не подтверждает появление игрового меню. Обнаружение записей Xbox не означает проверку каждой игры. Полная устойчивость к фоновым разговорам и собственному эху пока не подтверждена.
