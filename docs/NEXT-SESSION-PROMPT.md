# Промпт для продолжения в новом чате

Продолжаем разработку моего Windows-помощника JARVIS.

Рабочая папка: `F:\AI\JARVIS`.
Репозиторий: https://github.com/german-webdev/jarvis.git.

Сначала прочитай:
1. `F:\AI\JARVIS\docs\PROJECT-OVERVIEW.md` — отдельный актуальный документ: назначение, реализованные возможности, подтверждения, ограничения и планы. Мы будем использовать его и вне этой сессии; сохраняй ясное различие между готовым и запланированным.
2. `F:\AI\JARVIS\docs\SESSION-HANDOFF.md` — формат работы, технические решения, проверки, сборка и точка остановки.
3. При необходимости `F:\AI\JARVIS\docs\AI-CONNECTIONS-0.9.md` — текущая схема подключения нейросетей.

Предыдущую сессию остановили из-за лимита. Последняя версия — 0.9.2: переработан экран «Справка → Что я умею», добавлены сигнал на имя и ожидание следующей команды 5 секунд после ответа. Сначала проверь реальное состояние Git и выясни, есть ли мои замечания к этому обновлению. Не переделывай всё заново.

Я подтвердил успешный браузерный вход ChatGPT и отображение аккаунта. Получение реального ответа модели и озвучивание ещё не подтверждал. Подключения должны оставаться добровольными; поиск EXE руками мне не нужен. Базовые команды выполняются локально, нейросеть подключается по необходимости. Интерфейс русский/английский; голосовые команды пока русские. Подбор красивого роботизированного голоса отложен.

Следующее согласованное направление — дать нейросети инструменты для более сложных задач: сначала существующие навыки JARVIS и последовательности действий, затем управление браузером (YouTube, впоследствии Кинопоиск), затем интерфейс Windows. Это пока план, а не реализованный функционал. Нужны видимый ход выполнения, остановка, отдельные разрешения и проверка фактического результата каждого шага.

Работай по-русски, конкретно, без лишних подтверждений обычных исправлений. Береги рабочие настройки и авторизацию. Не выводи секреты, не подключай аккаунты и не делай оплаченные запросы автоматически. Для ручной проверки дай мне короткие действия; не перехватывай управление компьютером и не запускай захват экрана без необходимости. Выполняй подходящие проверки и обновляй документацию по результатам, отделяя тесты от реального пользовательского подтверждения.
