# Промпт для продолжения в новом чате

Продолжаем разработку моего Windows-помощника JARVIS.

Рабочая папка: `F:\AI\JARVIS`.
Репозиторий: https://github.com/german-webdev/jarvis.git.

Сначала прочитай:
1. `F:\AI\JARVIS\docs\PROJECT-OVERVIEW.md` — отдельный актуальный документ: назначение, реализованные возможности, подтверждения, ограничения и планы. Мы будем использовать его и вне этой сессии; сохраняй ясное различие между готовым и запланированным.
2. `F:\AI\JARVIS\docs\SESSION-HANDOFF.md` — формат работы, технические решения, проверки, сборка и точка остановки.
3. При необходимости `F:\AI\JARVIS\docs\AI-CONNECTIONS-0.9.md` — текущая схема подключения нейросетей.

Предыдущую сессию остановили из-за лимита. Последняя версия — 0.10.0: добавлен офлайн-установщик Windows x64 и короткое подтверждение «Подтверждаю»; ранее переработан экран «Справка → Что я умею», добавлены сигнал на имя и ожидание следующей команды 5 секунд после ответа. Сначала проверь реальное состояние Git и выясни, есть ли мои замечания к этому обновлению. Не переделывай всё заново.

Я подтвердил успешный браузерный вход ChatGPT и отображение аккаунта. Получение реального ответа модели и озвучивание ещё не подтверждал. Подключения должны оставаться добровольными; поиск EXE руками мне не нужен. Базовые команды выполняются локально, нейросеть подключается по необходимости. Интерфейс русский/английский; голосовые команды пока русские. Подбор красивого роботизированного голоса отложен.

Следующее согласованное направление — дать нейросети инструменты для более сложных задач: сначала существующие навыки JARVIS и последовательности действий, затем управление браузером (YouTube, впоследствии Кинопоиск), затем интерфейс Windows. Это пока план, а не реализованный функционал. Нужны видимый ход выполнения, остановка, отдельные разрешения и проверка фактического результата каждого шага.

Работай по-русски, конкретно, без лишних подтверждений обычных исправлений. Береги рабочие настройки и авторизацию. Не выводи секреты, не подключай аккаунты и не делай оплаченные запросы автоматически. Для ручной проверки дай мне короткие действия; не перехватывай управление компьютером и не запускай захват экрана без необходимости. Выполняй подходящие проверки и обновляй документацию по результатам, отделяя тесты от реального пользовательского подтверждения.

Пользовательская справка описывает общие возможности и шаблоны команд: «Запусти игру [название]», «Открой сайт [название]». Не превращать приложения, игры и сайты из личного обсуждения в перечень поддерживаемых возможностей. Не показывать вымышленные команды без названия, если они требуют записи или псевдонима в каталоге.

Дополнение к 0.9.2: «Закрой JARVIS» / «Закрой себя» полностью завершают приложение после прощания; «Открой JARVIS» / «Запусти JARVIS» отвечают точной выбранной пользователем фразой «А я кто, просячий хвостик?»; «Как дела?» — «Всё хорошо. На связи и готов помочь.». Всё локально, без нейросети. Проверку этих реплик голосом оставить пользователю.

Дополнение — питание ПК: «Выключи компьютер», «Перезагрузи компьютер», «Режим сна» / «Переведи компьютер в режим сна», «Гибернация» / «Переведи компьютер в гибернацию». Вместо «компьютер» также принимаются «компухтер», «компудахтер», «компутер» (включая разный регистр). Сон и гибернация — разные действия. Всё локально, без ИИ. Сначала JARVIS спрашивает подтверждение; «Подтверждаю» выполняют действие один раз. Любой другой ответ отменяет запрос. Голосовой ответ ждёт 10 секунд без повторного имени; текстовое подтверждение действительно 30 секунд. Stop/Esc отменяют запрос. Перед действием прослушивание останавливается; после пробуждения нажать «Начать». Гибернация и сон зависят от конфигурации Windows, JARVIS не включает их в системе автоматически.

Реальные выключение, перезагрузка и переходы питания при разработке не запускались. Проверка пользователем ещё нужна; не выключать его компьютер ради автотеста.


## Дополнение 0.10.0 — установочная версия

Подготовлен автономный установщик `F:\AI\JARVIS\artifacts\release\JARVIS-Setup-0.10.0-win-x64.exe` для Windows 10 build 19041+ / Windows 11 x64. Личные данные, аккаунты и каталоги разработчика исключены. Установленный профиль хранится в `%LOCALAPPDATA%\JARVIS`; рабочий прототип продолжает использовать свою папку `data`. Подробности сборки, установки, проверок и оставшихся ограничений — [INSTALLER-PLAN.md](INSTALLER-PLAN.md). Подсказка подтверждения теперь требует одно слово «Подтверждаю»; старое «да подтверждаю» также принимается для совместимости.
