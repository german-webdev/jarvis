# JARVIS — возможности, состояние и план развития

Актуально на 8 ноября 2026 года. Версия 0.9.2. Репозиторий: https://github.com/german-webdev/jarvis.

## Назначение

JARVIS — голосовой помощник для Windows. Пользователь говорит команду, приложение распознаёт её, выполняет действие и отвечает голосом. Базовые команды обрабатываются локально; нейросеть подключается по желанию для свободных вопросов. Автономное выполнение сложных задач через нейросеть пока находится в плане.

## Шаблоны команд

Вместо `[название]` пользователь произносит название из своего каталога. Скобки произносить не нужно. Это общие возможности; поддержка не ограничена приложениями, обсуждавшимися при разработке.

- «Открой браузер».
- «Запусти приложение [название]», «Запусти игру [название]».
- «Закрой приложение [название]», «Закрой игру [название]».
- «Открой папку [название]», «Открой каталог [название]».
- «Включи музыку», «Сделай потише», «Дальше», «Выключи музыку».
- «Открой сайт [название]», «Открой почту».
- «Спроси нейросеть [вопрос]» — при настроенном активном подключении.

Названия приложений зависят от локального каталога. «Выключи музыку» ставит плеер на паузу. Закрываемая программа может показать запрос сохранения или уйти в собственный трей. Кнопка «Стоп» и Esc на главном экране останавливают прослушивание и ответ; голосовое «стоп» вне уточнения означает паузу плеера.

## Что подтверждено, а что ещё требует проверки

Пользователь подтвердил запуск браузера и голосовой ответ; запуск приложений и игр, собственные названия и уточнения; улучшение распознавания имени; открытие сайтов. После исправления 0.9.1 пользователь отдельно подтвердил: браузерная авторизация ChatGPT завершилась, аккаунт отображается.

Успешный ответ модели по подписке и его озвучивание пользователь ещё не подтвердил. Настоящий вход Claude и реальная локальная модель Ollama не проверены. Для Claude прямой самостоятельный OAuth JARVIS не реализован: нужен официальный компонент Claude Code, который находится автоматически. Выбор EXE из интерфейса удалён.

Новая справка проверена рендерингом собственного WPF-окна, включая минимальный размер, поиск и пустой результат. Для продолжения разговора проверены пятисекундная тишина и завершение речи, начатой перед истечением срока. Сигнал и полная голосовая цепочка 0.9.2 требуют проверки пользователем на реальном микрофоне, особенно при выводе звука через колонки.

Надёжность при фоновом телевизоре, эхо, длительной игровой нагрузке и работе со всеми приложениями пока не подтверждена. Названия и склонения обрабатываются ограниченными локальными правилами, а не полноценным пониманием любого названия.

## Следующий этап: действия с помощью нейросети

Согласовано направление развития: нейросеть выбирает шаг, JARVIS выполняет его, возвращает наблюдаемый результат, затем выполняется следующий шаг. Этот режим ещё не реализован.

1. Предоставить нейросети существующие навыки JARVIS, добавить выполнение последовательностей и остановку задачи.
2. Добавить управление браузером: чтение страницы, поиск, выбор элементов, ввод и нажатия. Первые сценарии — поиск и запуск ролика на YouTube, затем поиск фильма на Кинопоиске.
3. Добавить управление интерфейсом Windows и анализ экрана при необходимости.
4. Сделать отдельные разрешения для навыков, браузера, компьютера и передачи изображения экрана; видимый текущий шаг и остановку. Предусмотреть подтверждение конкретных покупок, отправок и удаления файлов.

Подключение аккаунта не должно автоматически предоставлять управление компьютером. Простые команды остаются локальными. Возможности моделей и провайдеров нужно проверять отдельно: выбранный способ подписочного подключения поддерживает собственные функции приложения, но не все встроенные инструменты OpenAI.

- Подбор тембра и качественная роботизация голоса — отложены пользователем до завершения основных функций.

## Техническая основа и подробности

C# / .NET 10 / WPF / NAudio; отдельный Python 3.12 процесс, связь JSON Lines. Vosk определяет имя, Silero VAD выделяет речь, faster-whisper small CPU INT8 распознаёт команды, Piper синтезирует русскую речь. Пользовательские каталоги и настройки хранятся локально вне Git. API-ключи и сессия прямого ChatGPT-входа защищены Windows DPAPI.

Дополнение к 0.9.2: «Закрой JARVIS» / «Закрой себя» полностью завершают приложение после прощания; «Открой JARVIS» / «Запусти JARVIS» отвечают точной выбранной пользователем фразой «А я кто, просячий хвостик?»; «Как дела?» — «Всё хорошо. На связи и готов помочь.». Всё локально, без нейросети. Проверку этих реплик голосом оставить пользователю.

Дополнение — питание ПК: «Выключи компьютер», «Перезагрузи компьютер», «Режим сна» / «Переведи компьютер в режим сна», «Гибернация» / «Переведи компьютер в гибернацию». Вместо «компьютер» также принимаются «компухтер», «компудахтер», «компутер» (включая разный регистр). Сон и гибернация — разные действия. Всё локально, без ИИ. Сначала JARVIS спрашивает подтверждение; «Да, подтверждаю» или «Подтверждаю» выполняют действие один раз. Любой другой ответ отменяет запрос. Голосовой ответ ждёт 10 секунд без повторного имени; текстовое подтверждение действительно 30 секунд. Stop/Esc отменяют запрос. Перед действием прослушивание останавливается; после пробуждения нажать «Начать». Гибернация и сон зависят от конфигурации Windows, JARVIS не включает их в системе автоматически.

Реальные выключение, перезагрузка и переходы питания при разработке не запускались. Проверка пользователем ещё нужна; не выключать его компьютер ради автотеста.
