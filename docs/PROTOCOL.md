# Протокол голосового процесса v1

UTF-8 JSON Lines через stdin/stdout; stdout содержит только JSON. stderr предназначен для диагностики и всегда считывается хостом. Python не запускает приложения и не выполняет shell-команды.

| Направление | type | Основные поля |
|---|---|---|
| C# → Python | start | session: integer, mode: command или wake, wait_seconds: 4–15, по умолчанию 8 |
| C# → Python | audio | session, pcm: Base64, PCM16 little-endian mono 16 kHz; пакет до 1 секунды |
| C# → Python | cancel | session: новый номер; сбрасывает накопленный звук |
| C# → Python | synthesize | session, text: до 500 символов; voice: dmitri/denis; style: natural/robot/radio; amount: 0–1; rate: 0.85–1.2 |
| C# → Python | transcribe | session, pcm: до 20 секунд; техническая проверка записи |
| C# → Python | quit | завершение |
| Python → C# | loading | text: этап загрузки |
| Python → C# | ready | protocol: 1, asr, voice |
| Python → C# | listening | session, mode |
| Python → C# | activated | session |
| Python → C# | processing | session, keep_capture: boolean; хост выключает микрофон, если флаг отсутствует или false |
| Python → C# | awaiting_command | session; кандидат оказался одним именем или пустым текстом, ожидание продолжается |
| Python → C# | command_timeout | session; после имени команда не поступила, хост молча возобновляет ожидание имени |
| Python → C# | transcript | session, text, elapsed_ms |
| Python → C# | empty | session; речь не обнаружена |
| Python → C# | speech | session, wav: Base64 WAV с частотой синтезатора |
| Python → C# | error / fatal | session, text |

Хост принимает результат только для текущего session и не исполняет transcript повторно. Esc/«Стоп» немедленно выключает микрофон и меняет номер сеанса. Текущее вычисление в нативной библиотеке не прерывается мгновенно; поздний результат игнорируется. Перезапуск модуля завершает дочерний процесс.

Очереди ограничены 128 сообщениями. При переполнении исходящей очереди хост останавливает обработку и показывает ошибку; звук не отбрасывается незаметно. Python читает сообщения в отдельном потоке; тяжёлая обработка выполняется последовательно. В первой версии нет приоритетного канала отмены, автоматического перезапуска или фонового обновления моделей.

Silero обрабатывает блоки по 512 отсчётов. Перед началом фразы сохраняется короткий буфер; в режиме имени — до шести секунд. Vosk обнаруживает имя по частичному результату; временная граница слова отделяет имя, сохраняя начало команды без паузы. Повторно распознанное одиночное имя не передаётся маршрутизатору команд. Отсчёт ожидания идёт по входному аудио после границы имени; начавшаяся речь может закончиться после этого срока. Завершение команды: примерно 0,8 секунды тишины, максимум около 10 секунд фразы. Голосовой ответ проигрывается с выключенным микрофоном.

Поля синтеза необязательны для совместимости: по умолчанию dmitri/natural/0.45/1.0. Интерфейс передаёт сохранённый выбор явно. Громкость применяется на стороне C# при воспроизведении; звуковой эффект — на стороне Python до отправки WAV.

С версии приложения 0.3 команды `start` и `transcribe` могут содержать `vocabulary`: названия включённых приложений и свои варианты. Python ограничивает подсказку 1500 символами и передаёт её в hotwords распознавателя. Это подсказка для текста; право выполнять действия остаётся у хоста и точного маршрутизатора.
