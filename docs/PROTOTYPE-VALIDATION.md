В отдельных прогонах распознавание контрольной синтетической фразы занимало примерно **0,93–1,08 секунды** на CPU. Это время вычисления ASR, без ожидания конца реплики, загрузки моделей, запуска браузера и озвучки. Оно не является статистикой задержек живых команд или гарантией скорости.

## Что выявлено и исправлено

- WPF-индикатор уровня требовал явной односторонней привязки; устранено падение при открытии окна.
- В списке микрофонов исправлен слабый контраст. По умолчанию выбирается вход связи Windows вместо первого устройства в списке.
- Ограниченный процесс разработчика не мог нормально проверить браузер. Приложение проверено в обычном пользовательском сеансе; запуск от администратора не нужен.
- Исправлено повторное закрытие WPF-окна в обработчике Closing; дочерний процесс завершается до закрытия интерфейса.
- Отмена меняет номер сеанса, поэтому поздний результат распознавания не должен запускать действие.
- Прямая проверка голоса не включает микрофон после ответа даже при установленном флажке ожидания имени.

## Ограничения, которые остаются

1. Маленькая модель иногда неверно разбирает короткие синтетические фразы, особенно с именем. Добавлены подсказки словаря. Один удачный живой тест не подтверждает 95% точности; нужен набор голосовых примеров пользователя.
2. Ожидание имени проверено на синтетической записи. Ложные активации от фильма, разговоров и игровых звуков не измерялись. Начинать удобнее с кнопки «Слушать».
3. Голос Дмитрий — пробный; выразительность и произношение нужно оценить отдельно. Перед ответом микрофон выключается, поэтому полноценного голосового перебивания нет.
4. Проверка браузера подтверждает видимое окно нужного исполняемого файла. Она не доказывает появление конкретной новой вкладки, если браузер уже открыт.
5. Не проверены длительная работа, сон/пробуждение, отключение аудиоинтерфейса, смена вывода во время ответа, нагрузка в игре и GPU-профиль.
6. При зависании предлагается ручной перезапуск модуля. Нет автоматического восстановления, установщика, трея и автозапуска.

## Воспроизводимость

Версии Python-библиотек зафиксированы в `uv.lock`, C#-библиотек — в `packages.lock.json`, SDK — в `global.json`. Основные фактически установленные компоненты: .NET SDK 10.0.403, Python 3.12.13, NAudio 2.2.1, faster-whisper 1.2.1, CTranslate2 4.8.5, Piper 1.8.0, Vosk 0.3.45. Источники и SHA-256 моделей находятся в `models.lock.json`.

Команды проверки приведены в [README](../README.md). Синтетические записи и локальные отчёты сохраняются в исключённой из Git папке `work`. Аудио реального микрофона не сохранялось. История живой речи находится только в текущем окне приложения.
