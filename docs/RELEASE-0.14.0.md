## Короткая ручная проверка после самостоятельного обновления

Полностью выйти из JARVIS, включая трей, запустить установщик 0.14.0 и проверить сохранение прежних настроек. Для проверки выбирать подходящие приложения и действия, которые пользователь действительно хочет выполнить.

1. **Контекст:** спросить ИИ о двух пунктах → «объясни второй пункт проще» → нажать «Новый разговор» → убедиться, что прежний контекст больше не используется. Реальный ответ ChatGPT был подтверждён пользователем раньше, новый контекст ещё требует этой проверки.
2. **Задача ИИ:** при выбранном ChatGPT явно включить локальные задачи; попросить открыть добавленное EXE-приложение и переключиться на него. Сверить фактическое окно и результат. Проверить Stop между шагами. Если провайдер не принимает инструменты, сохранить точное сообщение; фиктивные ответы тестов не доказывают реальный tool calling.
3. **Сценарий:** сохранить свою точную фразу с двумя шагами «Открыть»/«Переключиться» для одного EXE; выполнить текстом, затем по желанию голосом. Проверить выключение сценария и Stop. Одно наблюдаемое окно не доказывает готовность документа или игры.
4. **Браузер:** в «Сайты → Видео YouTube» открыть управляемый браузер → «найди видео [запрос]» → выбрать второй результат → сверить название/канал и URL. Проверить Stop при поиске. Consent, login, недоступная сеть и изменённый DOM должны давать честное ограничение; воспроизведение автоматически не заявляется.
5. **Окно:** явно выбрать поддерживаемое окно → «опиши окно» → «выбери вкладку [уникальное название]» → сверить выбранное состояние. Проверить смену цели и Stop. Недоступная UIA-разметка или запрет фокуса являются ограничениями, обход не выполняется.

Отдельно для голосовой задачи при уже включённом микрофоне произнести «останови задачу» / «отмени задачу», проверить задержку, отсутствие дальнейших шагов/позднего ответа и освобождение захвата до TTS. Текстовый запуск не должен включать микрофон. Реальная запись/воспроизведение, чужие окна/браузер, публичные сервисы и аккаунты в автоматической сборке не использовались.

Звуки, таймеры, заметки, подбор тембра, постоянная память и GitHub-релизы/автообновления остаются отложенными; этот выпуск их не обещает.
