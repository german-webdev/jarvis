9 ноября 2026. По запросу пользователя собран локальный установщик для самостоятельной проверки. Сабагенты, GitHub CI, push и автоматическая установка не использовались.

Удалены «Окно», «Сценарии», «Новый разговор» и связанные реализации. Подробности отката: [ROLLBACK-2026-11-09.md](ROLLBACK-2026-11-09.md). Согласованные интерфейс, Mini JARVIS, темы и прочие прежние функции сохранены. Новая универсальная MCP-интеграция ещё не реализована.

- До упаковки отката пройдены 414 Core и 50 App тестов; после них изменены только номер выпуска и документация.
- Release publish выполнен из текущих исходников. EXE: FileVersion 0.14.1.0. Payload: `artifacts/installer-build-20261109-233257/payload`.
- Проверены точный набор и SHA-256 всех 5874 файлов пакета, отсутствие пользовательского профиля.
- Пакетный `--check-installation`: success=true, ready=true, синтез 34348 байт WAV. Использован .NET из payload. Микрофон и воспроизведение не включались.
- Inno Setup успешно создал установщик; лог `work/release0141-inno.log`. Сводка `work/release0141-summary.json`.
- Подготовка сторонних исходников через сеть остановилась из-за сертификата. Зависимости Python в новом пакете установлены по зафиксированным версиям и хешам; пины сравнены с предыдущим пакетом без комментария с путём команды. 37 файлов third-party взяты из пакета 0.14.0 после проверки его манифеста и SHA-256; обе копии речевого исходного кода сверены с текущим деревом.
