# JARVIS 0.15.0 · поиск через браузер

В **«Нейросети»** выбери активное подключение ChatGPT и включи **«Отправлять нейросети непонятные фразы»**. Скажи или введи «Открой YouTube и найди видео про котиков». На главном экране появятся названия из выдачи и кнопка «Открыть страницу». Кнопка «Стоп» и голосовая команда «Останови задачу» прерывают работу. Для браузера нужны интернет и Microsoft Edge.

Локальный установщик `artifacts/release/JARVIS-Setup-0.15.0-win-x64.exe`, 992044361 байт, без цифровой подписи. SHA-256 `2b47b12a246a70189781ecfa81ad3b4b9b5ce058ffba0b76904caa944f844880`. Перед обновлением полностью закрой JARVIS, включая трей.

## Что вошло

- JARVIS сначала разрешает точные локальные команды и уточнения. Невыполненная целиком просьба передаётся выбранной модели полным текстом. Прежний поиск видео из раздела «Сайты» остаётся доступен.
- ChatGPT получает локальный браузерный инструмент, а затем результат вызова. В контексте остаются шаги текущей задачи. Сеанс ограничен 100 секундами и четырьмя действиями модели.
- Playwright MCP 0.0.84 получает отдельный профиль Edge, который закрывается после задачи. Разрешены переходы на страницы результатов и видео YouTube, статьи русской и английской Википедии и `example.org`. Доступны переход и чтение снимка страницы. Текст сайтов передаётся модели как недоверенное наблюдение. Учётные данные сайтов, произвольный JavaScript и загрузка файлов недоступны инструменту.
- В выдаче YouTube подтверждение требует совпадения адреса поиска и наличия ссылок на видео в снимке. Показанные названия и адрес берутся из браузера. Свободный ответ модели сам по себе не подтверждает выполнение. При завершении браузер закрывается. Кнопка «Открыть страницу» открывает подтверждённый адрес в обычном браузере.
- Проверенное подключение для действий — прямой вход по подписке ChatGPT с `gpt-6.1-sol`. Профили API, Ollama и Claude пока остаются текстовыми. Условия подписочного маршрута: [OpenAI Docs](https://developers.openai.com/siwc/token-sharing-open-source/preview-limitations). Версия и лицензия модуля: [Microsoft Playwright MCP](https://github.com/microsoft/playwright-mcp/releases/tag/v0.0.84).

- Через текстовый маршрут приложения проверены «Открой YouTube и найди видео про котиков» и «Поищи на YouTube смешные ролики с кошками». Существующий вход ChatGPT обновил токен по штатному механизму. Оба запроса получили реальный список из видимого Edge. Проверены отправка наблюдения обратно модели, показ результата и выход приложения из состояния выполнения. Отдельно адаптер MCP прочитал `example.org` и выдачу YouTube в изолированном Edge.

Покрыты поздний ответ после отмены, завершение зависшего процесса MCP, ошибка инструмента, неподдерживаемые подключения, отсутствие результата без наблюдения, локальные команды, навигация, Mini и остановка голосовой задачи на тестовом аудиотракте.
- Проверены SHA-256 всех 6062 файлов payload и отсутствие пользовательского профиля. Автономный `--check-installation` использовал .NET из пакета, запустил речевой модуль, синтезировал 35372 байта WAV и подтвердил один инструмент после инициализации MCP. Пакет использует Node.js v22.22.3 и зависимости из `installer/browser/package-lock.json`.
- AppId и код обновления прежней версии сохранены. Установщик собран локально. Ручная установка поверх рабочей копии, физический микрофон и голосовая остановка в реальном окружении остаются для пользовательской проверки.
