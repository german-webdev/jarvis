# JARVIS 0.15.1 · результат сразу в браузере

- «Открой YouTube и найди видео про котиков» открывает готовую выдачу в браузере по умолчанию. При просьбе открыть конкретный ролик JARVIS сначала проверяет его страницу и открывает её. Вкладка остаётся открытой после завершения задачи. Автозапуск воспроизведения зависит от сайта и настроек браузера.
- Playwright проверяет публичную страницу в фоне, в отдельном профиле без звука. Подтверждённый адрес передаётся Windows через HTTPS. На компьютере пользователя Windows передала обе проверенные страницы Chrome.
- Успешный ответ на экране и в голосовом режиме — «Выполнено.». Названия из выдачи используются моделью при выборе ролика. Кнопка «Открыть страницу» убрана. Если проверка отменена до передачи адреса Windows, поздний результат не открывает вкладку.

## Проверки

- Через текстовый ввод с настоящим `gpt-6.1-sol` проверены поиск котиков и просьба запустить `Me at the zoo`. Оба запроса получили «Выполнено.». После окончания задач подтверждены видимые вкладки Chrome с выдачей и с точным роликом. Воспроизведение ролика и физический микрофон отдельно не проверялись.
- Прошли 417 Core и 76 App тестов, включая отмену после получения наблюдения, отказ системного браузера и передачу только итогового адреса. Проверены четыре отрисовки собственной главной страницы на русском и английском при двух размерах окна.
- Проверены хеши 6062 файлов payload. Проба из пакета использовала встроенный .NET, синтезировала 33324 байта WAV и инициализировала MCP. Переупакованы новые бинарники. 5589 файлов зависимостей сверены с манифестом 0.15.0 перед переносом.

Перед обновлением полностью закрой JARVIS, включая трей, затем запусти `artifacts/release/JARVIS-Setup-0.15.1-win-x64.exe`. Идентификатор установки сохранён. Установка поверх рабочей копии остаётся ручной проверкой.
