# JARVIS 0.16.0 · интернет и браузер

В разделе «Нейросети» выбери ChatGPT и включи «Отправлять нейросети непонятные фразы». Одной настройки достаточно для работы с общедоступными сайтами. Модель может открывать страницы, читать их, переходить по ссылкам, пользоваться вкладками, клавиатурой и полями форм.

- «Какая сейчас погода во Владивостоке?» читает актуальную страницу прогноза и возвращает короткий ответ. При запросе погоды без города JARVIS просит уточнить город.
- «Открой канал Шимура шоу» находит канал в выдаче YouTube, проверяет страницу `@SHIMOROSHOW` и открывает именно её. Если подтверждена только выдача, JARVIS сообщает об ошибке.
- По просьбе открыть страницу JARVIS передаёт подтверждённый адрес системному браузеру, оставляет вкладку открытой и говорит «Выполнено.». Вопрос о содержимом сайта получает устный ответ.

Рабочий браузер модели запускается в отдельном временном профиле Chrome или Edge. Состояние форм, cookies и входы этого профиля отделены от обычных вкладок. Сайт или поисковик может ограничить автоматический доступ. В проверке несколько поисковиков запросили CAPTCHA, а встроенный веб-поиск текущего подписочного подключения вернул пустой результат. Выпуск использует браузерные инструменты. Для работы с YouTube в регионах с экраном согласия временный профиль отклоняет необязательные cookies только при проверке ожидаемого канала.

## Проверки

- 417 Core и 94 App теста. Проверены общедоступные адреса за пределами прежнего списка, проверка назначения через DNS, разграничение ответа и открытия вкладки, подтверждение канала YouTube и продолжение работы после слишком большого снимка.
- На `gpt-6.1-sol` проверены реальный канал и большой документ RFC 9110 в обычном Chrome, а также короткий ответ о текущей погоде с чтением страницы Яндекс Погоды. Через Playwright выполнен переход по ссылке с `example.com` на сайт IANA.
- Проверены хеши 6062 файлов установочного пакета. Пакетная проба использовала встроенный .NET, синтезировала 32300 байт WAV и обнаружила 14 инструментов. Бинарники приложения опубликованы заново, 5589 неизменившихся файлов зависимостей сверены с манифестом 0.15.1.

Перед обновлением полностью выйди из JARVIS, включая значок в трее, затем запусти `artifacts/release/JARVIS-Setup-0.16.0-win-x64.exe`. Идентификатор установки сохранён. Установка поверх рабочей копии и физический микрофон остаются ручной проверкой.
