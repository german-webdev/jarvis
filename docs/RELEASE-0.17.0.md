# JARVIS 0.17.0 · обычный Chrome

В режиме **«Работать в моём Chrome»** JARVIS подключается к выбранному профилю Chrome через официальное расширение Playwright. Он использует действующие входы на сайтах, выполняет команду в рабочей вкладке и оставляет результат открытым. [Документация расширения](https://playwright.dev/mcp/configuration/browser-extension)

1. Полностью выйди из JARVIS, включая значок в трее, и запусти `artifacts/release/JARVIS-Setup-0.17.0-win-x64.exe`.
2. В **«Подключениях ИИ»** включи **«Работать в моём Chrome»** и нажми **«Установить расширение Playwright»**. Установи его в профиле Chrome, которым пользуешься для входа на сайты.
3. Нажми **«Открыть страницу кода»**, скопируй код из расширения, вставь в поле JARVIS и сохрани. Эту настройку достаточно выполнить один раз.

Код хранится зашифрованным средствами Windows. Выбранная нейросеть получает содержимое страниц, которые JARVIS читает для выполнения команды. Чтобы отключить подключение, сними галочку и сохрани настройки. При выключенном режиме браузерные задачи используют временный профиль.

Команда «Открой канал и запусти последнее видео» теперь заканчивается на странице ролика. JARVIS проверяет канал и использует его вкладку «Видео», чтобы найти свежую загрузку. После подтверждённого открытия он говорит «Выполнено.».

## Проверки

- Пройдены 417 Core и 98 App тестов, включая завершение составной команды, проверку вкладки загрузок и сохранение кода подключения.
- В отдельном тестовом Chrome с официальным расширением JARVIS прочитал страницу, которой передался заранее сохранённый cookie профиля. Отключение инструмента оставило рабочую и соседнюю вкладки открытыми.
- Подписочное подключение `gpt-6.1-sol` получило точный текст со скриншота «Открой канал шаморошоу и запусти последнее актуальное видео». В Chrome открылся первый ролик из свежих загрузок SHIMOROSHOW. Проверено воспроизведение, одна вкладка с роликом и ответ «Выполнено.».
- Установочный пакет прошёл проверку хешей 6062 файлов, встроенного .NET, синтеза речи и 14 браузерных инструментов. Пользовательский профиль в пакет не входит. Идентификатор установки сохранён. Подключение личного профиля и физический микрофон остаются ручной проверкой.
