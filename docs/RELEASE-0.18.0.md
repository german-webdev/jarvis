# JARVIS 0.18.0

Исправлена ошибка на просьбе «Открой пожалуйста почту». Запрос списка вкладок возвращал страницу подключения Playwright, а JARVIS пытался проверить её как обычный сайт. Теперь список вкладок обрабатывается отдельно. Если почтовый сервис неизвестен, модель может спросить, какую почту открыть. Для прямого открытия можно сказать «Открой Gmail», «Открой Яндекс Почту» или назвать адрес сайта.

Настройка «Разрешить ИИ запускать приложения» действует для всех подключений. Она разрешает запуск включённых приложений из каталога и переключение на их окна. Сохранённое значение прежней настройки переносится автоматически. Браузер доступен выбранной нейросети при включённой обработке неизвестных команд.

Подключения API, Ollama и Claude Code теперь получают инструменты и наблюдения через общий протокол структурированных JSON-ответов. Исполнение проходит через существующие проверяемые браузерные и локальные инструменты. ChatGPT использует существующие нативные вызовы функций. Выбранная модель должна соблюдать формат структурированного ответа. Некорректный ответ прекращает задачу с объяснением.

Проверены 417 Core и 102 App теста. Тесты API и Ollama проверяют передачу инструментов, возврат наблюдения модели и завершение на подтверждённой странице. Эти проверки используют тестовый HTTP-сервис. Работа с реальными моделями API, Ollama и авторизованным Claude Code в этом выпуске не проверялась.

На подключённом ChatGPT и отдельном тестовом Chrome воспроизведена исходная ошибка. После исправления список вкладок читается успешно, неопределённая просьба о почте получает уточняющий вопрос. По команде «Открой Gmail» открывается страница входа Gmail, доступная тестовому профилю, и остаётся открытой. Вход в личный почтовый ящик пользователя остаётся ручной проверкой. Расширение предоставляет вкладки своего сеанса, поэтому модель не получает автоматически список всех ранее открытых вкладок Chrome.

Настройки отрисованы на русском и английском в обычном и минимальном размерах окна. Проверен автономный пакет из 6062 файлов, встроенный .NET, синтез речи и обнаружение 15 инструментов. Предупреждение NU1900 при сборке относится к недоступности сетевого списка уязвимостей NuGet.

Перед обновлением полностью выйди из JARVIS, включая значок в трее, и запусти `artifacts/release/JARVIS-Setup-0.18.0-win-x64.exe`. Локальный установщик без цифровой подписи. Код подключения Chrome сохраняется в профиле JARVIS.
