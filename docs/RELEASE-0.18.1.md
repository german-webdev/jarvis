# JARVIS 0.18.1

Настройка называется «Работать в моём браузере». Рядом находится кнопка «?», открывающая справку при наведении или нажатии. В справке описана работа в текущем профиле браузера на базе Chromium через расширение Playwright, использование входов на сайты и необходимость сохранить новый код при смене профиля.

Подключение и кнопки настройки используют браузер по умолчанию. Для стандартных каналов Playwright сохраняется автоматический выбор профиля с расширением. Для других браузеров передаётся зарегистрированный в Windows исполняемый файл. Сохранённый код подключения прежней версии переносится автоматически. Внутреннее имя поля `ProtectedChromeToken` сохранено для совместимости данных.

Расширение использует Chromium API debugger и tabGroups. Возможность установить расширения сама по себе не подтверждает совместимость конкретного браузера с Playwright. Проверенный ранее сеанс Chrome сохраняется. Работа Opera и Яндекс Браузера в этой версии отдельно не проверялась. Firefox требует другого способа подключения. [Описание Playwright](https://playwright.dev/mcp/configuration/browser-extension).

Пройдены 417 Core и 108 App тестов. Проверены выбор канала для разных имён браузеров и прежние сценарии работы с инструментами. Интерфейс отрисован на русском и английском при обычном и минимальном размере окна, DPI 100%. Проверка других DPI в этом выпуске не выполнялась.

Перед установкой полностью закрой JARVIS, включая значок в трее. Установщик `artifacts/release/JARVIS-Setup-0.18.1-win-x64.exe` обновляет прежнюю копию с сохранением профиля.
