# Навыки и автоматический каталог · 0.3

Пользователь подтвердил работоспособность версии 0.2. Подбор тембра и роботизация отложены: сначала функциональность.

## Выполняемые команды

| Фраза | Действие |
|---|---|
| Открой браузер | Браузер Windows по умолчанию |
| Запусти Telegram / телеграм | Найденный клиент Telegram |
| Запусти Steam / стим | Клиент Steam |
| Открой Xbox / икс бокс | Клиент Xbox |
| Запусти игру Call of Duty | Установленная игра по официальному названию |
| Запусти колду | Та же игра, если «колда» добавлена в свои названия |
| Сделай скриншот / Сделай снимок экрана | Все мониторы одним PNG в `data/screenshots` |
| Открой скриншоты | Папка снимков |
| Сделай громче / Сделай тише | Системная громкость ±10 процентных пунктов |
| Громкость 30 процентов / Громкость тридцать пять процентов | Точная системная громкость 0–100 |
| Выключи звук / Включи звук | Mute / unmute устройства вывода Windows |
| Сколько времени / Какое сегодня число | Время или дата компьютера |
| Покажи команды | Краткий перечень возможностей |

Mute и нулевая громкость подтверждаются текстом. Изменение громкости не снимает mute; для этого есть «Включи звук». Микрофон не используется для текстовых команд. Игры не закрываются командой «Стоп».

## Как устроен каталог

Меню **Джарвис → Приложения и игры → Найти установленные**:

1. Windows предоставляет зарегистрированные приложения из AppsFolder, включая приложения и игры Xbox, представленные в каталоге Windows.
2. Steam предоставляет расположения библиотек через `libraryfolders.vdf`. Из каждой библиотеки читаются `appmanifest_*.acf`; запись включается при наличии признака установленного приложения и его папки.
3. Новые записи добавляются с официальными названиями. Свои названия необязательны: несколько вариантов разделяются точкой с запятой. Для однословного русского прозвища на «а» также принимается форма на «у»: «колда» → «колду».
4. Повторный поиск не перезаписывает пользовательские варианты и отключённые записи. Пропавшие записи пока сохраняются, чтобы не терять настройки; перед запуском игры Steam наличие установки проверяется повторно.
5. **Добавить файл** позволяет выбрать `.exe` или `.lnk`, если приложение не найдено автоматически.

Официальное название сопоставляется без учёта регистра, знаков пунктуации и «ё/е». Нет нечёткого выбора «похожей» игры. Если несколько включённых записей имеют одинаковое название, помощник просит различить их; можно выключить дубль или дать разные дополнительные названия. Двойные записи одного приложения Windows объединяются при обнаружении.

Распознавание английского имени на слух может выдать кириллицу. Это ограничение ASR: собственные русские варианты полезны, но не обязательны. Имена включённых записей передаются распознавателю как подсказки словаря (до 80 вариантов, ограничение на стороне Python 1500 символов).

Xbox-игры, не зарегистрированные в AppsFolder, и нестандартные портативные установки могут не обнаружиться. Здесь остаётся ручной вариант; обход DRM, установка игр и автоматическое нажатие кнопок лаунчера не выполняются. Обнаружение игр Epic/GOG и других библиотек пока не добавлено.

## Архитектура выполнения

`CommandRouter.Resolve → CommandRequest → SkillDispatcher → ISkill → SkillResult`

Маршрутизатор выбирает точное намерение и параметры. Исполнители работают с Windows: браузер, запуск записи каталога, аудиоустройство, снимок, дата/время. `MainViewModel` управляет сеансом, показывает результат и запускает озвучку. Ошибка одного навыка возвращает сообщение и не отключает речевой модуль. Отмена проверяется до исполнения; поздние ответы старого сеанса игнорируются.

`SkillResult.Verified` отделяет подтверждённый результат от передачи команды. Для громкости читается состояние устройства, для скриншота сохраняется PNG. Запуск через Steam или AppsFolder подтверждает передачу запроса, но не загрузку игрового меню: лаунчер может показать вход, обновление или ошибку. Ответ поэтому звучит «Передал команду запуска…».

Пути и идентификаторы берутся из сохранённого каталога; распознанная речь не превращается в shell-команду. Локальные данные `data/apps.json`, `data/settings.json` и снимки исключены из Git.

## Проверка

- Модульные проверки: официальные названия без дополнительных вариантов, свои названия, колда/колду, неоднозначность, отключение записи, отрицания и составные запросы, диапазон громкости, отмена, изоляция ошибки навыка, чтение Steam и сохранение каталога.
- `--scan-apps <путь в work>` — диагностический поиск без запуска приложений и микрофона.
- `--test-command <фраза> --report <путь в work>` — реальное выполнение текстовой команды, включая её побочные действия. Для обычного использования есть меню **Джарвис → Команда текстом**.
- `scripts/test_speech.py` — прежний тест реальных моделей и ожидания имени после добавления подсказок каталога.

Источники интерфейсов: [Microsoft: обнаружение AUMID](https://learn.microsoft.com/en-us/windows/configuration/store/find-aumid), [Microsoft PowerToys: запуск AppsFolder](https://github.com/microsoft/PowerToys/blob/main/src/modules/Workspaces/WorkspacesLauncher/AppLauncher.cpp), [Valve: Steam browser protocol](https://developer.valvesoftware.com/wiki/Steam_browser_protocol), [Microsoft: виртуальные экраны](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-getsystemmetrics). Steam VDF/ACF разбирается по локальным манифестам; формат следует повторно проверять при изменениях клиента.
