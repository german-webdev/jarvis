# Окна, воспроизведение и папки · 0.5

Все команды обрабатываются локально. Windows API подключены через `net10.0-windows10.0.19041.0`; облачные модели не добавлены.

| Задача | Примеры |
|---|---|
| Закрыть окно программы | «Закрой телеграм», «Выключи стим», «Закрой сабнавтику» |
| Закрыть запущенную игру Steam | «Закрой игру»; при нескольких окнах — уточнение |
| Закрыть активное внешнее окно | «Закрой окно», «Закрой текущее приложение» |
| Свернуть | «Сверни окно», «Сверни активное окно» |
| Переключиться | «Переключись на браузер», «Переключись на телеграм» |
| Пауза и продолжение | «Пауза», «Поставь на паузу», «Продолжи», «Сними с паузы» |
| Треки | «Следующий трек», «Предыдущая песня» |
| Папка игры | «Открой папку с Сабнавтикой», «Открой каталог Форзы», «Открой папку с игрой Subnautica» |
| Папка программы | «Открой папку Телеграма», «Открой каталог программы Telegram» |

## Выбор цели

Запуск и открытие папки используют каталог установленных программ. Закрытие и переключение используют снимок открытых видимых окон, включая свёрнутые. Для Steam окно связывается с каталогом установки игры, для обычных приложений — с исполняемым файлом, известным именем процесса или Windows AppUserModelID. По случайному упоминанию названия программы в заголовке чужого окна закрытие не выполняется. Некоторые нестандартные ярлыки, старые UWP-окна и защищённые процессы могут не сопоставиться по имени.

При нескольких совпадениях задаётся голосовой вопрос. Ответ выбирает исходное действие: «Закрой форзу» → «шестую» закрывает выбранное окно; «Открой папку Форзы» → «шестую» открывает каталог части. Существующий диалог отмены, ограничения числа вариантов и тайм-аутов сохранён. Идентификатор окна включает процесс, время его запуска и дескриптор. Перед действием они проверяются ещё раз; исчезнувшее окно не заменяется другим.

«Браузер» обозначает открытые окна браузера по умолчанию. Если их несколько, закрывается только выбранное. «Закрой игру» относится к окнам, сопоставленным с установленными играми Steam; игру Xbox можно называть по имени, если Windows предоставляет подходящий AppUserModelID.

## Закрытие и переключение

Используется `WM_CLOSE`, а не принудительное уничтожение процесса. Приложение может показать запрос сохранения, отказаться закрываться или спрятаться в трей. Джарвис различает исчезновение окна и отправку неподтверждённого запроса. «Выключи телеграм» — синоним обычного закрытия окна, не гарантия выхода из фонового процесса. Выключение компьютера этим правилом не поддерживается.

Окна самого Джарвиса, рабочий стол, панель задач и системные фоновые процессы исключены. «Закрой окно» / «Сверни окно» действуют на окно, находящееся на переднем плане в момент выполнения. Если впереди Джарвис, помощник предлагает назвать приложение.

Windows может отказать в переносе фокуса. Джарвис проверяет результат и сообщает об отказе; права администратора и имитация нажатий для обхода ограничения не используются. [Правила SetForegroundWindow](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setforegroundwindow).

## Плеер

Используется текущая медиасессия Windows (`GlobalSystemMediaTransportControlsSessionManager.GetCurrentSession`). Это позволяет управлять совместимыми браузерами и плеерами без отправки пробела случайному окну. Пауза и продолжение — отдельные операции: повторная пауза не возобновляет музыку. Перед командой проверяется поддержка операции, после паузы / продолжения — сообщаемое плеером состояние. Для следующего / предыдущего трека подтверждается передача запроса, а не фактическая смена песни.

Если медиасессии нет или плеер не поддерживает действие, помощник сообщает об этом. Выбор плеера по имени, открытие фильма на Кинопоиске и управление воспроизведением внутри игры остаются отдельными задачами. [Медиасессии Windows](https://devblogs.microsoft.com/oldnewthing/20231108-00/?p=108980).

## Папки

- Steam: свежий манифест установленной игры и её `installdir` в библиотеке. Старые записи каталога работают без пересканирования.
- `.exe`: папка существующего файла.
- `.lnk` и обычные приложения Windows: целевой путь зарегистрированного ярлыка; его командная строка не исполняется.
- Пакеты Windows / Xbox: `InstalledLocation` зарегистрированного пакета текущего пользователя. Папка может быть защищена или указывать на пакет, а не на отдельный каталог содержимого игры.

Путь передаётся Проводнику отдельным аргументом. Если путь не найден, удалён или недоступен, нет перебора всего диска, изменения владельца папки или прав доступа. Генитив и творительный падеж простых русских вариантов добавлены к существующим правилам: «Форзы / Форзой», «Сабнавтики / Сабнавтикой», «Телеграма / Телеграмом». Это ограниченные правила, а не полная модель русской морфологии.

Результаты проверок — [отчёт 0.5](V0.5-VALIDATION.md).
