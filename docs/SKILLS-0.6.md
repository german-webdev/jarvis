# Музыка и распознавание названий · 0.6

## Названия приложений

Локальные правила склоняют последнее русское слово составного названия: «Яндекс Музыка» → «Яндекс Музыку», «Яндекс Музыки», «Яндекс Музыкой». Это ограниченные правила окончаний, а не полный морфологический анализ русского языка. Словарь произношений отдельных английских слов применяется к любому названию из каталога: например, `password manager` → «пасворд менеджер» / «пассворд менеджер».

Word получает варианты «ворд», «уорд», `ward`, `wardo`; Excel — «эксель», «экссель», «экзель». Однозначно распознанное название запускается сразу: наличие WARDOGS не вызывает дополнительного вопроса для Word. Уточнение требуется только если название или псевдоним действительно совпадает у нескольких записей. Тогда ответить можно названием или «вариант один» по озвученному списку, без повторения имени Джарвис.

Свои названия разделяются запятой, точкой с запятой или переносом строки. Старые записи с несколькими фразами в одной строке также работают без повторного сохранения. Свои названия остаются необязательными.

Для закрытия и переключения зарегистрированные приложения дополнительно сопоставляются с окнами по полному пути исполняемого файла. Поэтому имя процесса `kpm` или `WINWORD` не должно лишать окно названий из каталога. Закрытие остаётся обычным запросом окну: программа может показать диалог сохранения или уйти в трей.

## Музыка

| Команда | Действие |
|---|---|
| Включи музыку / Запусти музыку / Давай музыку | Выбрать музыкальное приложение, открыть при необходимости и передать Play |
| Пауза | Приостановить выбранный плеер |
| Продолжи | Возобновить выбранный плеер |
| Дальше / Следующий / Следующий трек | Следующий трек |
| Назад / Предыдущий / Предыдущий трек | Предыдущий трек |

При нескольких установленных музыкальных приложениях Джарвис уточняет выбор голосом. Выбор сохраняется. Его можно изменить в **«Настройки → Музыка»**. Явный запуск музыкального приложения по названию также запоминает его для следующих команд.

В автоматическом режиме открытое музыкальное приложение имеет приоритет перед браузером, даже если музыка на паузе, а видео играет. Несколько подходящих плееров требуют выбора. Если выбранный плеер исчез, команда не переключается молча на YouTube. Без музыкального приложения и сохранённого выбора допускается единственная доступная медиасессия, в том числе видео в браузере.

После запуска приложение ожидается до 12 секунд. Если оно не предоставило медиасессию, помощник просит выбрать музыку внутри приложения и повторить «продолжи». Поиск песни и выбор плейлиста не реализованы. Поддержка Play/Pause/Next/Previous зависит от самого плеера и его интеграции с Windows.

## Окна и каталог

После обычной попытки переключения окна добавлен ограниченный по времени резервный способ через Windows UI Automation. Итог проверяется по фактическому окну на переднем плане. Защищённые и повышенные окна могут остаться недоступными; настройки безопасности Windows не меняются.

Таблица каталога получила одинаковые внутренние отступы заголовков и ячеек, вертикальное выравнивание текста и флажков, фиксированную высоту строк и спокойное выделение. Длинные варианты сокращаются многоточием; полный автоматический список доступен при наведении.

Все изменения работают локально. Подбор голоса остаётся отдельным будущим этапом.
