# Сайты · 0.7

Команда открывает сохранённый HTTP/HTTPS-адрес в браузере по умолчанию. Распознавание названия и выбор сайта выполняются локально; облачный ИИ не используется.

| Команда | Адрес |
|---|---|
| Открой YouTube / ютуб | https://www.youtube.com/ |
| Открой Кинопоиск | https://www.kinopoisk.ru/ |
| Открой почту / Gmail / почту Гугла | https://mail.google.com/ |
| Открой почту Яндекса / Яндекс почту | https://mail.yandex.ru/ |
| Открой Ozon / озон | https://www.ozon.ru/ |
| Открой Яндекс еду | https://eda.yandex.ru/ |
| Открой ПлатиМаркет / плати маркет | https://plati.market/ |

В меню **«Джарвис → Сайты»** можно добавить, удалить, выключить или изменить сайт. Редактируются название, адрес и дополнительные названия через запятую. Двойной щелчок по ячейке начинает редактирование; изменения применяются после «Сохранить». «Отмена» оставляет прежний каталог. Голосовые псевдонимы обрабатываются теми же правилами, что приложения, включая доступные склонения.

«Открой сайт …» выбирает только среди сайтов, «Открой приложение …» — среди приложений. Если обычное «открой …» подходит нескольким записям, Джарвис уточняет выбор. Ответ «вариант один» / «вариант два» выбирает по озвученному списку. Удалённые или выключенные записи не запускаются.

Каталог хранится отдельно в `data/sites.json`; поиск игр и приложений его не меняет. При отсутствии файла предлагаются семь исходных сайтов. После сохранения учитывается пользовательский список, в том числе пустой. Адрес можно ввести с HTTPS или как домен без схемы — тогда добавляется HTTPS. Локальные адреса HTTP допускаются; произвольные команды, файловые адреса и другие схемы не исполняются.

Ответ «Открываю сайт …» означает передачу адреса браузеру. Он не подтверждает загрузку страницы, вход в аккаунт, доступность сервиса или воспроизведение фильма. Используется обычный профиль браузера; Джарвис не вводит пароли и не читает почту. Поиск видео, запуск фильма и действия внутри страницы ещё не реализованы.
