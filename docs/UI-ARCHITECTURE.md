# Интерфейс и взаимодействие · 0.7

Главный экран отвечает на три вопроса: что делает помощник, что он услышал и чем закончилось действие. Настройка устройств и поведения выполняется отдельно. Будущие навыки добавляются в выполнение команд и настройки соответствующей категории, без новых технических панелей на главном экране.

## Карта экранов

| Область | Содержимое |
|---|---|
| Главный экран | Состояние, пояснение, звуковая волна, «Начать» / «Стоп», последняя команда и ответ |
| Журнал на главном экране | Последние 30 событий текущего сеанса, скрытие через меню «Вид» |
| Нижняя строка | Включён ли микрофон, способ обращения, характер голоса |
| Настройки → Микрофон | Выбор входа, обновление устройств |
| Настройки → Голос | Тембр, эффект, сила эффекта, темп, громкость, предварительное прослушивание |
| Настройки → Музыка | Предпочтительное приложение или автоматический выбор |
| Настройки → Поведение | Активация кнопкой или именем, время ожидания команды |
| Настройки → Приложение | Журнал, уменьшение анимации, перезапуск речевого процесса |
| Меню «Справка» | Поддержанные команды |
| Меню «Джарвис» → Приложения и игры | Автоматическое обнаружение, свои названия, включение записей, ручное добавление |
| Меню «Джарвис» → Сайты | Названия, адреса, псевдонимы, добавление и выключение сайтов |
| Меню «Джарвис» → Команда текстом | Выполнение навыков без распознавания речи |

Настройки — отдельное модальное окно. При открытии прослушивание и текущий ответ останавливаются. Изменения редактируются в черновике; «Прослушать» использует черновик, «Сохранить» применяет и записывает настройки, «Отмена» отбрасывает изменения. Закрытие настроек само не включает микрофон. При следующем запуске микрофон также выключен.

## Состояния

`Loading → Idle → WaitingForName → Listening → Recognizing → Executing → Synthesizing → Speaking`

В кнопочном режиме пропускается ожидание имени. После ответа режим имени возвращается к ожиданию; кнопочный режим — в покой. Имя без продолжения приводит к молчаливому возврату. «Стоп» и Esc из любого рабочего состояния выключают микрофон/ответ, меняют номер сеанса и возвращают в покой. Ошибки переводят в `Fault` с пояснением и возможностью перезапустить модуль.

Волна рисуется локально средствами WPF: уровень входа при прослушивании, уровень выходного сигнала при ответе. Цвет различает ввод, ответ и ошибку. Частота отрисовки ограничена 30 кадрами/с; в покое постоянная анимация не нужна. Опция уменьшения движения отключает движение фазы волны, сохраняя реакцию на громкость.

## Границы кода

- `MainWindow` — разметка главного экрана и открытие окон; `MainViewModel` — текущее состояние и координация сеанса.
- `SettingsWindow` / `SettingsViewModel` — черновик настроек, предварительное прослушивание и сохранение.
- `AssistantSettings` / `SettingsStore` — версия формата, допустимые значения, атомарная запись в `data/settings.json`. Ошибка чтения сохраняет исходный файл и даёт безопасные значения по умолчанию.
- `VoiceVisualizer` — отображение состояния и уровня, без распознавания и выполнения команд.
- `Ui` и `Localization/strings.json` — русский и английский интерфейс. WPF-ресурсы и подписи состояния обновляются при сохранении языка; исходные команды, названия и голосовые ответы не переводятся.
- `AudioService`, `WorkerClient`, `BrowserLauncher` — адаптеры звука, речевого процесса и запуска браузера.
- Python `Interaction` — граница между именем и командой, ожидание, отмена. `Engine` — модели, `voice_effects` — обработка готового голоса.
- `CommandRouter` — ограниченное распознавание намерений без запуска программ. Исполнение остаётся в Windows-хосте.

В версии 0.3 исполнители вынесены из `MainViewModel`: `CommandRequest → SkillDispatcher → ISkill → SkillResult`. Реализованы запуск из каталога, громкость, скриншоты, дата/время; подробности — [SKILLS-0.3.md](SKILLS-0.3.md). Следующие навыки добавляются через этот интерфейс. Облачный ИИ и история между запусками остаются будущими расширениями.

В версии 0.8 `TrayIcon` обслуживает значок и меню Windows, `StartupRegistration` управляет только записью автозапуска текущего пользователя. `CloseChoiceWindow` возвращает выбор без управления голосовым модулем: скрытием и окончательным завершением занимается `MainWindow`. `App` обеспечивает единственный экземпляр и передаёт повторному запуску запрос восстановления окна. При выходе из сеанса Windows диалог пропускается. Подробности: [DESKTOP-0.8.md](DESKTOP-0.8.md).

В версии 0.6 правила выбора плеера находятся в MusicSelection, работа с медиасессиями Windows — в MusicPlayback / MediaControl. Выбор хранится как идентификатор каталога MusicTargetId. WindowControl связывает окна с зарегистрированными исполняемыми файлами через AppLocations; резервное переключение WindowFocus выполняется отдельным процессом с пределом ожидания 3 секунды. Названия и разделители своих фраз централизованы в NameVariants, чтобы каталог, команды и подсказки распознавателю использовали одни правила.
