# Доработка 0.12.2 · 9 ноября 2026

Пользователь уточнил: переходы между разделами и работа с настройками/каталогами не должны останавливать JARVIS. Ручная остановка — кнопкой «Стоп». Также указал на размытие значка в боковой панели.

## Реализация

- Удалены Stop и отмена ожидающего автопрослушивания из навигации; удалены Stop при выгрузке настроек и обработчики остановки по Esc. Esc по-прежнему может закрывать справку/диалог, не затрагивая голосовую сессию.
- Настройки из трея и сохранение настроек доступны во время работы. Оформление/язык сохраняются без смены сессии. Прослушивание образца, обновление устройств и перезапуск модуля остаются недоступными, пока ассистент занят.
- Сохранение настроек не сбрасывает ожидающее подтверждение питания. Само подтверждение, срок действия и отмена кнопкой «Стоп» сохранены.
- Открытие текстового ввода не останавливает работу. Если ассистент становится занят, отправка недоступна; текст и окно сохраняются. Добавлена проверка непосредственно в обработчике отправки.
- Боковая панель использует исходный PNG 1254×1254 с качественным уменьшением; ICO остаётся для заголовка окна, трея и ярлыка.
- Справка исправлена под новое поведение. Это заменяет прежнее описание приостановки при навигации в документации 0.12.1.
