# Единая кнопка голоса · 0.12.3

9 ноября 2026 пользователь выбрал второй из предложенных вариантов: одна круглая кнопка со значками микрофона и квадрата вместо пары текстовых «Начать»/«Стоп».

## Поведение и оформление

- Контурный микрофон запускает прослушивание; круг с заливкой и квадратом останавливает текущую работу. Во время распознавания, выполнения команды, синтеза и озвучивания доступен квадрат.
- Состояние остановки включает короткий промежуток перед возвратом к ожиданию имени. Нажатие в этот момент отменяет отложенное возобновление.
- В отсутствие готового модуля или выбранного устройства запуск недоступен. Наличие активной операции имеет приоритет над запуском.
- Значки — геометрия WPF, без растягивания растровых изображений. Диаметр круга 64 DIP, внешняя область 72 DIP с местом для кольца клавиатурного фокуса. Используются семантические цвета текущей темы.
- Стандартная кнопка сохраняет управление с клавиатуры, показывает hover/pressed/disabled, локализованные подсказку и доступное имя. Убраны две прежние кнопки только на главной; остановка из трея сохранена.
- Подписи состояния и справка описывают микрофон/квадрат. Навигация по-прежнему не останавливает прослушивание.

## Проверки

315 Core и 18 Windows — успешно. Расширен сценарий окна: квадрат виден во всех активных фазах и паузе перед возобновлением, его нажатие отменяет текущий token; в покое возвращается микрофон, без выбранного устройства запуск отключён. Проверены доступное имя и tooltip. Тест имитирует состояние и не записывает реальный микрофон.

Созданы 16 контролируемых WPF-рендеров главной страницы: RU/EN, светлое/тёмное оформление, покой/работа, обычный/минимальный размер. Активное состояние задано тестовыми данными; голосовой модуль и запись не запускались. Экспорт 150% не подменяет проверку смены DPI монитора.
