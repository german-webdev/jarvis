# JARVIS 0.13.2 · 9 ноября 2026

Все замечания из [последовательного плана](UI-FEEDBACK-0.13.2-PLAN.md) реализованы в одном локальном обновлении. Пользовательскую установленную версию автоматически не меняли; GitHub CI/push не запускали.

## Изменения

- **Mini:** кольцо на животе остаётся по центру при изменении DPI. Причина воспроизведена: независимое округление векторных деталей давало смещение на один физический пиксель при 125%. У внутренней векторной композиции отключено округление компоновки; рисунок и анимации сохранены.
- **Настройки Mini:** размещаются ниже/сбоку в доступной рабочей области, с проверкой границ мониторов и отрицательных координат. Резервируется место под максимальный размер робота, чтобы диалог не перемещался за указателем во время изменения размера.
- **Размер:** плавный бегунок 60–160% вместо трёх вариантов. Изменение вида и размера видно сразу; автоматическое сохранение через 250 мс и при закрытии. Save/Cancel убраны. При ошибке записи появляется сообщение; закрытие не теряет последнюю правку. Старые размеры преобразуются в 80/100/130%.
- **Сайдбар:** свёрнутые области выделения 48×48, все семь значков центрированы. Новый значок сворачивания обозначает боковую панель.
- **Кнопки:** верхние действия одинакового размера 40×40, постоянная акцентная рамка, изменение фона при наведении/нажатии. Переход в Mini обозначен стрелкой, согласованной с обратным переходом. Мышиный клик не оставляет отдельную рамку фокуса; клавиатурный фокус различим.
- **Заголовок:** только JARVIS.
- **Голос:** отдельный параметр «Тон голоса», −6…+6 полутонов, шаг 0,5; исходное значение 0. Скорость регулируется отдельно. Настройка используется обычной речью и образцом голоса; сохраняется общей кнопкой настроек. При нулевом значении исходные WAV-байты не изменяются. Смена тона сохраняет частоту дискретизации и число отсчётов; новые зависимости не добавлены.
- Изменения Mini сохраняют активную голосовую сессию и черновики основных настроек. Размер кнопок Mini не зависит от размера робота.

## Границы проверки и следующий шаг

Следующий шаг — пользовательская проверка 0.13.2: перетаскивание между мониторами, изменение размера при открытых настройках, новые кнопки и комфортный тон выбранного голоса. Субъективное качество звучания не оценивалось прослушиванием; на крайних значениях меняется и тембр. Если на всех экранах физически нет места одновременно для обоих окон, алгоритм выбирает положение с минимальным перекрытием. Настройки могут сохранять безопасное место на соседнем мониторе.
