- 113 тестов C#: новые фразы, склонения для папок, действие после уточнения, исчезновение окна, отрицания, составные команды, отсутствие запуска при попытке закрыть приложение, прежние навыки.

## Windows

`tests/Jarvis.DesktopProbe` создаёт отдельные дочерние тестовые окна и беззвучный MediaPlayer с медиасессией Windows. Пользовательские приложения не закрываются и их медиасессии не получают команды. Результат — `work/desktop-probe.json`, `success: true`.

Проверены:

- сворачивание, восстановление и переключение тестового окна;
- точность ответа о фокусе: Windows может отклонить первоначальную попытку, и помощник сообщает об отказе; обхода запрета нет;
- закрытие обычного окна;
- сохранение окна, отменяющего `Closing` (аналог запроса сохранения документа);
- отказ повторно закрывать исчезнувший объект;
- пауза, повторная пауза без возобновления, продолжение;
- доставка команд следующего / предыдущего трека тестовому плееру;
- определение папки исполняемого файла и реальных каталогов Subnautica, Telegram и пакета Xbox на этом компьютере.

Запуск теста на подготовленном Windows:

```powershell
$env:DOTNET_ROOT = Join-Path (Get-Location) '.tools/dotnet'
.\.tools\dotnet\dotnet.exe publish tests/Jarvis.DesktopProbe/Jarvis.DesktopProbe.csproj -c Release -o artifacts/desktop-probe
.\.tools\dotnet\dotnet.exe artifacts/desktop-probe/Jarvis.DesktopProbe.dll (Get-Location).Path
```

Тест зависит от интерактивного рабочего стола Windows, не входит в CI и не доказывает совместимость каждого плеера или игры. Дочерние тестовые процессы удаляются из памяти после проверки; данные пользовательских приложений не меняются. Пути к личным установленным программам остаются в локальном отчёте `work`, исключённом из Git.

## Что проверить голосом

Сквозная команда в готовом приложении «Открой папку с сабнавтикой» дошла до Проводника и озвучки. Дерево интерфейса Проводника подтвердило путь `F:\SteamLibrary\steamapps\common\Subnautica`. Локальный `folder-smoke.json` содержит `success: false`, потому что исполнитель папки подтверждает только передачу запроса Проводнику; наличие открытого каталога проверено отдельно по интерфейсу.

1. «Открой папку с Сабнавтикой», «Открой папку Телеграма».
2. На запущенной программе: «Закрой телеграм». При уходе в трей фоновый процесс может продолжить работу — это штатное поведение программы.
3. Во время музыки / видео: «Пауза», повторно «Пауза», «Продолжи».
4. «Переключись на браузер». Несколько окон — выбор голосом. Windows может ограничить перевод фокуса.
5. При активном внешнем окне: «Сверни окно». Если на переднем плане сам Джарвис, действие не выполняется.

Живое подтверждение пользователя относится к названиям версии 0.4. Для новых действий версии 0.5 оно пока не получено. Защищённые папки Windows / Xbox, нестандартные приложения и игры с собственными лаунчерами могут требовать отдельной проверки; изменение прав доступа и принудительное завершение не предусмотрены.
