# Проверка версии 0.7 · 8 ноября 2026 года

- 200 проверок C#: семь исходных сайтов, Gmail по слову «почта», формы «почту Яндекса» / «Яндекс еду», пользовательские названия, разделение сайта и приложения с одним именем, уточнение реальных совпадений, выключенные и неизвестные сайты, сохранение адресов и пустого каталога, ограничения схем адресов и предыдущие навыки.
- 31 проверка Python и Ruff прошли. Голосовые модели не менялись. Известное ограничение синтетического «Громче» из отчёта 0.6 остаётся отдельным открытым случаем.
- Сборка приложения прошла. В меню появилась отдельная страница «Сайты», таблица проверена визуально: одинаковые отступы, редактируемые названия/адреса/псевдонимы, флажки включения.
- Через кнопку «Сохранить» создан `data/sites.json`; чтение файла подтвердило все семь запрошенных адресов, включая `https://plati.market/`. Каталог приложений при этом не менялся.
- Сквозная текстовая команда «Открой сайт ПлатиМаркет» выполнена готовым приложением; получен ответ «Открываю сайт ПлатиМаркет». В списке окон появилось окно Chrome с заголовком «Plati.Market — площадка цифровых товаров». Доступ к содержимому страницы отдельно не подтверждён: ожидание разрешения интерфейса браузера истекло.

`work/site-smoke.json` содержит `success: false`, поскольку исполнитель сайта подтверждает передачу адреса, но не загрузку страницы. Это ожидаемая граница результата, а не доказательство ошибки открытия. Подтверждение окна браузера получено отдельно. Вход в почту, чтение писем, покупки и воспроизведение фильмов не выполнялись. Проверка голосовых фраз пользователем ещё ожидается.
