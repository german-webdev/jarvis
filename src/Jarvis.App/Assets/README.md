# Значок JARVIS

`jarvis.png` — исходный рисунок, созданный встроенным генератором изображений 8 ноября 2026 года. `jarvis.ico` — Windows-формат того же рисунка с размерами 16, 24, 32, 48, 64, 128 и 256 пикселей. Пересоздание ICO: `scripts/export-icon.ps1`. Прозрачность сохраняется; дополнительной правки рисунка не было.

Значок используется в EXE, главном окне и трее. Ярлык берёт значок из EXE.

## Запрос генератору

Use case: logo-brand. Asset type: Windows application icon for a Russian local voice assistant named JARVIS, used as an EXE, desktop shortcut and system tray icon. Create ONE finished square icon, not a mockup or sheet. Original futuristic voice-assistant mark: a bold geometric letter J integrated with a simple circular listening signal. Thick clean forms, immediately readable at 16 and 32 pixels, few details. Polished restrained sci-fi style. Palette matching existing app: bright mint/turquoise #64DCC6 and icy cyan on a solid very dark navy #0D1928 rounded-square tile. Strong contrast, subtle dimensional bevel only, no fine concentric rings or tiny decorations. Tile fills about 90 percent of square canvas, centered; genuinely transparent outside rounded tile. No text except the single abstract J mark, no slogan, no watermark, no additional objects, no scene background, no Marvel or Iron Man imagery. Deliver professional crisp icon artwork.
